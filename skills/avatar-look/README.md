# avatar-look

会看向鼠标的 3D 头像组件

## 要解决的问题

想在个人网站上放一个会看向鼠标的 3D 卡通头像，手上只有一张照片或一个想法。没有这个 Skill 时，要自己在 Three.js、眼神网格图、视频之间选方案，自己给视频模型写提示词，再临时写脚本裁视频、算朝向、写跟随代码。按姿态挑帧转起来一顿一顿，帧图混合在快速转头时有重影，这些坑要一轮轮试出来。

## 运行方式

![avatar-look 结构图](../../docs/diagrams/avatar-look.jpg)

AI 先出 3D 头像图，再把即梦的设置、提示词和挑选标准交给用户；生成视频是唯一必须用户动手的一步。视频交回后，脚本自动裁切、量朝向并自检：头没转满一圈或认不出脸，就说清哪条没达标、请用户换备选提示词重生成。最后复制组件、接入用户点名的页面，自动验收，并在用户实际访问的地址上再测一次跟随，之后由用户亲手试手感。手上已有头像图或视频，可以从第 2、3 步直接进。

## 关键设计

一个看向鼠标的头像要同时做到三件事：长相不走样，屏幕上任何方向都有对应的画面，转起来连贯。avatar-look 用一段头绕一圈的视频当素材，处理脚本把视频量成一条首尾相接、记着每帧朝向的时间轴，网页组件按鼠标方向沿这条时间轴逐帧跳转。

- **素材是一段头绕一圈的视频**：首帧和尾帧都用同一张 3D 头像图，让视频模型生成头上下左右绕一圈、身体和机位不动的视频，每一帧都是这个形象本身。出图和生视频的提示词、挑选标准在 `references/prompts.md`，提示词每一句对应一项要求。
- **播放头沿时间轴连续走过每一帧**：`process_video.py` 量出每帧头朝哪，把绕圈那段按方向角排成首尾相接的时间轴；视频转多了就裁成正好一圈，接缝选首尾最像的两帧；首尾差了几帧的角度没拍到，就用光流在首尾之间补帧接上；短促且头没朝下的眨眼帧不进时间轴。`avatar-look.js` 只算鼠标相对头像中心的方向，播放头按最短路径追向目标、途经每一帧，头像放在哪、显示多大都不用改代码。
- **任意一帧都能立刻跳到**：`process_video.py` 把视频压成每帧都是关键帧的 H.264，跳到哪一帧都只解码这一帧；`avatar-look.js` 用 seeked 串联跳转，上一次没跳完时只记下最新目标，等跳完再跳，每一次跳转都落到画面上。
- **处理和验收都留下可核对的数据**：`process_video.py` 输出九宫格核对图和自检报告，记下人脸识别率、首尾缺口、裁掉和补上的帧、相邻帧的画面差；`verify.py` 在 Chrome 里打开 `demo.html`，测 8 个方向的偏差、快速画圈时每秒跳转次数、慢转一圈时有没有倒退或跳帧、控制台报错。接入页面后，还要在用户实际访问的地址上绕着头像移动鼠标，读视频当前帧确认头跟着转。
- **组件只有一份，三行接进页面**：`avatar-look.js` 是唯一的组件代码，复制进产出目录使用，要改行为就改它再重新复制；跟手快慢、最高转速、鼠标离开或停着不动多久回正脸这些手感参数写在文件开头，用户说卡、飘、慢时对照 `references/how-it-works.md` 调。

```text
avatar-look/
├── SKILL.md               五步流程、从哪步进入、交付格式
├── references/
│   ├── prompts.md         出头像图和生视频的提示词、挑选标准
│   └── how-it-works.md    原理、手感参数、卡顿怎么对症改
├── scripts/
│   ├── process_video.py   裁切编码、量朝向、建时间轴并自检
│   └── verify.py          在 Chrome 里测方向、跳转速度和跟随
├── assets/
│   ├── avatar-look.js     组件：按鼠标方向跳到对应的视频帧
│   └── demo.html          三个头像的演示页，验收也用它
└── examples/
    └── orange-cat/        例子：从一句话想法出戴耳机的橘猫头像
```

## 其他

- 前提：ffmpeg、uv（脚本用 Python 3.12 临时环境装 MediaPipe）、playwright + 本机 Chrome（验收）；生图默认走本机 Codex 的 image_gen，失败两次或用户不满意，就给提示词让用户自己出
- 注意：转动幅度只跟方向走，不随鼠标远近变化；只在 Chrome 实测过，Safari 未验证；本地预览接入的页面时，服务器要支持 Range 请求（Python 自带的 http.server 不支持），否则头一直是正脸不转
