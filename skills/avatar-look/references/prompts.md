# 提示词与操作指引

人工环节（出头像图、生视频）读这份。给用户的每一段都按「去哪做、怎么设置 → 提示词 → 挑选标准 → 做完回我什么」的顺序。

## 目录

1. 3D 头像图：要求、提示词（照片版 / 想法版）、谁来出、挑选标准
2. 绕圈视频：即梦设置、提示词（主版 + 两个备选）、挑选标准、都不行时

## 1. 3D 头像图

### 这张图要满足什么（也是挑选标准）

- 3D 卡通渲染风格（皮克斯类），半身像，**正脸、居中、身体正对镜头**
- **纯色浅背景**：放进圆形头像框时边缘干净
- **头顶留出空间**：帽子、头发在转头时不能出画
- 16:9 横版。这是验证过的比例：即梦首尾帧在 16:9 下转得完整；1:1 没试过
- 表情自然微笑，眼睛睁开看镜头
- 是照片版时：发型、眼镜、帽子、衣服等辨识特征和照片一致

### 提示词：照片版（附上用户照片）

```
参照附图人物，生成一张 3D 卡通渲染风格的半身肖像，皮克斯动画电影质感。
保留人物的辨识特征：发型、脸型、眼镜、帽子、衣服款式和颜色都与附图一致。
人物正脸面向镜头，身体和肩膀正对镜头，位于画面正中；表情是自然的微笑，眼睛看向镜头。
头顶上方留出约画面高度六分之一的空白，画面下沿到胸口。
背景是干净的纯浅米白色，无任何物体、文字和阴影图案；柔和的摄影棚光，正面主光。
16:9 横版，高清。
```

### 提示词：想法版

把 `<人物描述>` 换成用户的想法（物种 / 年龄 / 发型 / 配饰 / 衣服 / 气质），其余照抄：

```
生成一张 3D 卡通渲染风格的半身肖像，皮克斯动画电影质感。人物：<人物描述>。
人物正脸面向镜头，身体和肩膀正对镜头，位于画面正中；表情是自然的微笑，眼睛看向镜头。
头顶上方留出约画面高度六分之一的空白，画面下沿到胸口。
背景是干净的纯浅米白色，无任何物体、文字和阴影图案；柔和的摄影棚光，正面主光。
16:9 横版，高清。
```

非人类形象（机器人、动物吉祥物）也能用，但要有能识别的「脸」：MediaPipe 是按人脸关键点量朝向的，认不出脸的形象，第 3 步的脚本会报识别率不足。

### 谁来出

- **默认 agent 用 codex image_gen 出**。在 Claude Code 里按全局 CLAUDE.md 的生图规则调 codex：提示词写进文件，任务文件写清提示词路径、16:9 PNG、复制到的目标路径，收尾只回一行 `GENERATED:<路径>` 或 `FAILED:<原因>`。宿主本身就是 Codex 时直接用 image_gen。照片版要把照片路径写进任务文件，让它作为参考图。
- 出图失败两次，或用户看了不满意、想自己出：把上面的提示词给用户，告诉他去 ChatGPT（image 2）、即梦图片生成之类的图生图工具，上传照片 + 粘贴提示词，生成后把图片路径发回来。
- 用户只说「呆」「怪」「假」「不像」这类结论词时，先请他从这几个维度里点一个再改：神态（表情僵、眼神空）、光线（太平、太暗）、写实度（太像照片、太卡通）、比例（头太大、五官失真）、构图（不居中、头顶太挤）。10-20 用户说「太呆」，实际是神态和光线：张嘴大笑、瞪眼、正面平光；改成眼神有焦点、笑意到眼睛、45° 侧光加轮廓光后通过。正脸、居中、头顶留白、纯色背景是做视频的硬条件，改神态时不要动。

## 2. 绕圈视频

### 即梦设置（告诉用户）

- 入口：即梦 → 视频生成 → **首尾帧**模式
- 首帧和尾帧**都上传同一张 3D 头像图**：视频从正脸开始、回到正脸结束，转一圈正好闭合
- 时长 5 秒（动作太赶就选 10 秒）；比例跟随图片（16:9）
- 同一个提示词生成 3–4 条，从里面挑最好的一条

### 主版提示词

```
人物上半身正对镜头，肩膀和身体全程保持静止，只有头部和颈部运动。

人物像用鼻尖在空中缓慢画一个完整的圆：从正面看向镜头开始，先微微抬头看向正上方，然后顺时针依次看向右上方、正右方、右下方、正下方、左下方、正左方、左上方，回到正上方，最后回到正面看向镜头。头部转动幅度约20度，眼睛始终看向头部转动的方向，眼神略微领先于头部。

整个过程速度均匀、缓慢、连续，没有停顿，没有加速。表情始终保持温和的微笑不变，全程不眨眼。

帽子和眼镜随头部一起刚性转动，形状不变形；头发、衣服、背景、光线保持不变。纯净的浅米白色背景。

摄影机完全固定，水平视角，85mm人像镜头效果，无推拉、无摇移、无变焦、无景深变化。
```

按形象改一处：没有帽子、眼镜的，把「帽子和眼镜」换成实际的硬物配饰（耳机、发箍），没有就删掉这半句。

### 备选 B：短句版（主版走不圆时试）

```
固定机位人像。人物正对镜头，身体静止，头部缓慢做一圈完整的顺时针绕圈动作，鼻尖在空中画出一个圆，幅度约20度，眼睛跟随头部方向看向四周。匀速、连贯、无停顿。保持温和微笑，不眨眼。帽子和眼镜不变形，背景纯净浅米白，光线不变。无推拉摇移，无变焦。
```

### 备选 C：时间轴版（速度忽快忽慢、漏方向时试）

```
摄影机完全固定，水平视角，85mm人像镜头效果。人物上半身正对镜头，肩膀和身体全程静止，只有头部和颈部运动，眼睛始终看向头部转动的方向。

0-0.5秒：正面看向镜头，开始微微抬头。
0.5-1.5秒：看向正上方，再转到右上方。
1.5-2.5秒：转到正右方，再转到右下方。
2.5-3.5秒：转到正下方，再转到左下方。
3.5-4.5秒：转到正左方，再转到左上方。
4.5-5秒：回到正上方，再回到正面看向镜头。

头部转动幅度约20度，速度均匀连续，各方向之间平滑过渡，不停顿。表情始终保持温和微笑，全程不眨眼。帽子和眼镜随头部刚性转动，不变形；头发、衣服、背景、光线不变。纯净浅米白背景。
```

### 为什么这样写（改提示词时别丢）

| 写进去的 | 为什么 |
|---|---|
| 鼻尖画圆 + 逐个方向 | 鼠标在屏幕任何方向都要有对应画面 |
| 摄影机固定、身体静止 | 网页里只该有头在动，背景晃会穿帮 |
| 眼睛看向转动方向 | 「看向鼠标」的感觉主要来自眼神 |
| 全程不眨眼 | 鼠标停在哪帧画面就停在哪帧，停在眨眼帧像闭眼 |
| 表情不变 | 不同方向表情不一致很怪 |
| 不写粉尘、发丝浮动、冷酷 | 小头像框里粉尘只显脏；「冷酷」和笑脸冲突，表情会中途变 |

### 挑选标准（告诉用户逐条看）

1. 头真的绕了一整圈：上、下、左、右都到位，不是只在左右来回摆
2. 从头到尾还是这个人，脸没走样
3. 帽檐、眼镜框等硬物没变形
4. 全程没眨眼（偶尔一次可以接受，脚本会剔除）

挑好后把 mp4 的路径发回来。

### 都不行时

- 三条都没转满一圈：换备选 B、C 各生成 2–3 条
- 仍不行：换别的支持首尾帧的视频模型（如可灵），设置和提示词不变。这条路本 skill 没实测过，告诉用户
- 第 3 步脚本自检报的问题，对照这里的挑选标准告诉用户是哪一条没过
