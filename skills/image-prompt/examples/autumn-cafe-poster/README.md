# 示范：一句海报需求 → 一段能直接出图的 prompt

日期：2026-11-06 · 使用的 Skill：image-prompt

## 给了什么

一句话（原文见 [input/需求.md](input/需求.md)）：

> 我家楼下的社区咖啡店秋天要上新品桂花拿铁，想做一张竖版海报贴在店门口。标题写「秋天的第一杯桂花拿铁」，下面一行小字「11月15日起 每天限量 50 杯」。帮我把生图的描述写好，我拿去出图。

没指定用哪个生图模型，没给店名，也没给参考图。

## 怎么调用的

在 Claude Code 里把这句话原样发出去，没有点名 Skill，image-prompt 自己被调起。它按固定流程走：

1. 读需求：用途是贴在店门口的竖版海报，要上图的字有两段；
2. 没指定模型，按默认的 codex 内置生图写，读参数卡确认它没有可调参数，竖版比例只能写进 prompt；
3. 读场景模板里「海报」一节，按交付物 → 主体 → 光线 → 文字 → 排除的顺序写；
4. 交付前对一遍：要上图的字是否逐字给全、有没有排除多余的字和 logo、看图要点是否具体。

## 交出了什么

完整交付见 [output/交付.md](output/交付.md)，四块：

- **用途和模型**：一行，说明没指定模型所以用默认的 codex 内置生图；
- **prompt 原文**：可以整段复制（单独存在 [output/prompt.txt](output/prompt.txt)）。第一句说清是一张竖版 2:3 的门店海报；标题拆成两行、写清字体和颜色；最后一句排除了文字以外的数字、价格、logo；
- **参数**：codex 没有可调参数，比例已写进 prompt；
- **出图后要检查的地方**：标题和小字逐字核对、杯子上有没有多出来的字、桂花画得对不对、印刷裁边。

最后列出替你定了哪些：写实照片风格、热饮白瓷杯、标题分两行、配色，以及因为没给店名所以没放店名。

## 照这段 prompt 出的图

把 prompt 原文交给 codex 内置生图，出了一张 1024×1536 的海报：[output/海报.png](output/海报.png)。

![照 prompt 出的海报](output/海报.png)

按交付里「出图后要检查的地方」对了一遍：

| 检查项 | 结果 |
|---|---|
| 标题「秋天的第一杯」「桂花拿铁」 | 逐字正确，按要求分两行，第二行更大 |
| 小字「11月15日起 每天限量 50 杯」 | 逐字正确，数字是阿拉伯数字 |
| 多出来的字、价格、logo | 没有 |
| 桂花 | 一簇簇橙黄小花长在叶腋，叶子是深绿椭圆形；但小花画成了五瓣，真的桂花是四瓣 |

要更像真桂花，可以在 prompt 里把「米粒大小的橙黄色小花」改成「米粒大小、四片花瓣的橙黄色小花」再出一次。
