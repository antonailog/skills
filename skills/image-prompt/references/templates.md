# 场景模板

需求属于下面某一类时，先看那一节再写。模板是骨架不是成品：方括号换成具体内容，用不上的行删掉，别为了填满而编细节。模板里写进 prompt 的画幅，渠道有参数时删掉、改走参数（SKILL.md 写法第 8 条）。每节末尾的「容易错」直接改写进交付里的「看图时查什么」。

| 类 | 节 |
|---|---|
| 摄影 | 1 写实人像 · 2 写实动物与视频首帧 · 3 产品图与电商模特图 · 4 电影剧照 · 5 概念场景与大尺度建筑 · 6 年代感随手拍 |
| 带字的设计 | 7 海报 · 8 封面与头图 · 9 信息图、科普图、幻灯片 · 10 Logo |
| 插画 | 11 插画与角色设定 |
| 多张与动图 | 12 组图与故事板 · 13 GIF 动图 |
| 改图 | 14 局部编辑 · 15 多参考图合成、同一人换场景 |

## 1 写实人像（写真、街拍、棚拍）

```text
一张[用途：写真组图里的一张 / 街拍 / 棚拍人像]，写实摄影。
人物：[年龄段、外形：发型发色、妆容、服装，再加一个能认出来的小特征]。
场景：[地点]，[时间、天气]。
动作与表情：[在做什么]，[看向哪里]，[表情]。
构图：[竖版/横版]，[特写/胸像/半身/全身]，[平视/低机位/俯拍]，人物在画面[位置]。
光线：[光源和方向：左侧窗光 / 机身闪光正面直打 / 黄金时刻逆光]，[光偏软/偏硬]。
质感：[CCD 随手拍 / 35mm 胶片颗粒 / 单反浅景深]。保留真实的皮肤纹理、毛孔、碎发和衣服褶皱，不要磨皮。
画面里不要有文字。
```

容易错：手（手指数、握东西的姿势）、背景里的招牌字和路人肢体、皮肤像蜡。同一个人出多张时，外形那一句每张原样复用。

## 2 写实动物与视频首帧

```text
一帧写实纪录片风格的画面[，用作图生视频的首帧]。
主体：[动物：品种、毛色、花纹、眼睛颜色等能认出来的特征]，[正在做什么，和哪件物品怎么接触：两只前爪握着木柄锅铲]。
场景：[地点和陈设]，[时间]。
构图：[16:9 / 9:16]，[中景/近景]，平视；[动作要往哪边走，那一侧留出空间]。
光线：[自然侧光 / 侧逆光]，浅景深。
真实的[猫]身体结构，爪子是[猫]爪不是人手，物品是真的被握住、被碰到。
画面里不要有文字。
```

容易错：拟人动作把爪子画成人手、道具悬空；异瞳、花纹这类指定特征被画反。做首帧时画动作的起点，不画动作已经完成的样子，视频才接得下去。

## 3 产品图与电商模特图

产品：

```text
一张用于[电商主图 / 详情页 / 广告]的商业产品摄影。
产品：[名称、颜色、材质、大小感，标签在哪、标签上写「…」]。
摆放：放在[什么表面]上，[角度]，背景是[纯色 / 场景]。
光线：[柔光主光从左上方]，[阴影偏软/偏硬]，准确表现[玻璃 / 金属 / 皮革]的反光。
构图：[画幅]，产品在画面[位置]，[右侧 / 顶部]留空给后期排字。
产品的形状、比例和标签位置要合理；不要出现其他产品、文字或 logo。
```

电商模特：

```text
一张电商[女装 / 男装]模特图，写实摄影，像[棚拍 / 街拍]实拍。
模特：[年龄段、身形、发型]，穿[款式、颜色、面料、细节：几颗纽扣、口袋在哪]。
姿势：[站姿 / 走动]，双手[放在哪]，[全身 / 半身]。
背景：[纯色棚拍 / 街景]，光线[柔和均匀]。
身体结构正常：两只手、两条腿，手指自然；衣服的版型、颜色和细节与描述一致。
```

容易错：模特图翻车集中在手反、多一条腿、头被裁掉。手里有真实商品图时改用第 15 节，让模型照着实物画，文字描述代替不了实物。

## 4 电影剧照

```text
一帧[片种：华语都市爱情片 / 科幻片]里的电影剧照，真实摄影。
[人物外形]正在[动作]，地点是[场景]，[天气 / 时间]。
景别：[中景 / 特写 / 广角远景]，机位[高度]；前景[元素]，中景[主体]，背景[元素]。
光线：[主光]，[环境：霓虹倒影 / 雨 / 雾 / 尘埃]，色彩[冷暖关系]。
质感：[35mm 胶片颗粒 / 宽银幕]，浅景深。
画面里不要有字幕和文字。
```

容易错：一句里塞两个景别（「广角特写」）；剧照要有「正在发生」的动作，人物摆拍感太重就不像剧照。

## 5 概念场景与大尺度建筑（壁纸）

```text
一张[风格名]风格的概念摄影[，用作手机竖屏壁纸 / 桌面壁纸]。
主体：[建筑或地景：材质、形状、重复的元素]。
尺度参照：[一个很小的人 / 一列小火车]，在画面[位置]，[只有米粒大小]。
构图：[竖版 / 横版]，[仰视 / 航拍俯视 / 平视远景]，[对称 / 一点透视]。
光线与天气：[阴天漫射光 / 晨雾 / 夜里亮着的窗]，[色调]。
材质细节：[清水混凝土的模板接缝、雨水冲出的锈痕、青苔]。
画面里只有[这一个人]，没有文字。[壁纸：画面上部避开时钟和图标区域]
```

容易错：大场景各家都画得出，差别在细节——几百扇重复的窗是不是横平竖直、材质像不像真的、尺度参照的比例对不对。风格名是小众词（砼核、梦核这类）时，补一句它长什么样，模型未必认识这个词。

## 6 年代感随手拍（要以假乱真）

```text
一张[年份]拍的[彩色反转片 / 黑白胶片 / 早期数码相机]照片，像[普通游客随手拍 / 家庭相册里的一张]。
画面：[地点，以及那个年代该有的东西：建筑、招牌、交通工具、人物服装]。
构图：随手拍的构图，[主体不居中 / 稍微歪 / 前景被挡住一点]。
光线：[当时的自然光 / 闪光灯直打]。
质感：[褪色、颗粒、轻微过曝]，不要任何后期感，不要出现现代物品。
```

容易错：破绽在年代细节——车型、招牌字体、服装款式、电线杆。「随手拍」比「专业摄影」更像真的。照着一张真照片写时，逐项描述照片里看得见的东西，原图不给模型。

## 7 海报

```text
一张[主题]的[电影院线海报 / 活动海报 / 促销海报]，[竖版 2:3]。
视觉中心：[主体]，[真实摄影质感 / 插画]。
背景：[颜色 / 场景]。
文字只有这些：
- 标题「…」，位于[顶部 / 中下]，[粗体无衬线 / 书法 / 高对比衬线]，最大
- 标语「…」，位于[…]
- 底部信息「…」
层级：标题 > [主体] > 标语 > 底部信息；标题缩成手机缩略图也看得清。
除了上面这些文字，不要出现其他文字、数字、水印或 logo。
```

容易错：中文小字最容易错字、缺字；字越少越稳，底部小字能删就删。每一段字出图后逐字核对。

## 8 封面与头图

```text
一张[公众号头条封面 / 小红书封面 / 视频封面]，[画幅]。
内容：[文章或视频讲什么，一句话]。
画面：[一个一眼能懂的主体或场景]，[主体占画面多少、在哪一侧]。
文字：标题「…」，位于[另一侧 / 上方]，粗体、高对比，缩到手机缩略图也能读。
[或者：画面里不放字，[左侧 40%] 留空给后期加字。]
风格：[…]。除标题外不要其他文字。
```

画幅：公众号头条封面 2.35:1，后台还会从同一张图里裁一张 1:1 小图，主体放中间；小红书 3:4；视频封面 16:9。

容易错：主体和标题抢位置；标题压在脸上。

## 9 信息图、科普图、幻灯片

```text
一张关于[主题]的[竖版信息图 / 16:9 演示幻灯片]，给[受众]看。
版式：[分几块、怎么排：从上到下 4 个阶段 / 左图右文]，用[箭头 / 编号]连起来。
内容只用下面这些，不要补充我没给的数据和标签：
1. 「[标签]」：[这一块画什么]
2. …
文字：大而清楚，无衬线字体，不用装饰字体；画面里只出现上面列出的文字。
风格：[扁平插画 / 写实插图 / 简洁图标]，[配色]，浅色背景。
```

容易错：模型自己补的数字和标签是编的，所以内容必须由用户给全；标签超过 6 个就拆成两张。小字多的图在 GPT Image 上把 quality 调高，见 models.md。

## 10 Logo

```text
一个原创标志，品牌名「…」，[图形标 / 文字标 / 图文组合]。
气质：[三个词]。核心图形：[元素]。
清晰的几何形状和轮廓，缩到很小仍能认出；[单色 / 双色：哪两种颜色]；留出合理的负空间。
[纯白背景 / 透明背景]，不要渐变、阴影、额外文字和装饰。
```

要矢量文件时，用 GPT Image 2.6 的 SVG 输出（参数见 models.md），prompt 里写「干净的矢量式形状，轮廓清楚，扁平，少描边，非必要不用渐变」。要透明背景时，prompt 写「孤立的主体，无背景」，同时在参数里设透明——画出来的灰白棋盘格不是透明。

容易错：细节过多，缩小后糊成一团。

## 11 插画与角色设定

```text
一张[媒介：日系二次元插画 / 手绘水彩绘本插画 / 厚涂 / 宋代绢本设色]。
角色：[固定外形描述，多张原样复用]。
在做什么：[动作]；场景：[…]。
构图：[…]。线条与上色：[赛璐璐平涂 / 水彩晕染 / 工笔]。
[角色设定图：同一角色的正面、侧面、背面三视图并排，比例和服装细节一致，纯色背景。]
画面里不要有文字。
```

容易错：仿传统绘画时要写清笔法、设色、透视方式（如「散点透视」），再加「不要出现任何现代物品」；只写「古风」会得到一张现代插画。

## 12 组图与故事板

```text
[一张 6 格故事板，3 列 × 2 行 / 同一角色的一组 4 张图]，讲[故事概要]。
角色：[固定外形描述]，每一格里身份、服装、道具都一样。
镜头顺序：
1. [建立镜头：…]
2. [中景：…]
3. […]
每一格的动作接着上一格；全组风格、色调一致。[格子之间留细白边，不要编号和文字。]
```

容易错：一张图里出多格时，格数和排列要写死；分开出多张时，每张都带同一段角色描述，并把第一张作为参考图一起给。

## 13 GIF 动图

GPT Image 2.6 能直接出 GIF（API 和 ChatGPT 都行，帧数、每帧时长走参数，见 models.md）。动作和循环写在 prompt 里：

```text
[主体和场景，一两句]。[主体]从[起始姿势]开始，[依次做哪几个动作]，然后回到起始姿势。
[始终不变的东西：手里一直拿着灯笼 / 背景不动 / 服装不变]，镜头[固定不动 / 缓慢平移]。
动作首尾无缝循环。
```

在 ChatGPT 里出，开头再加一句「做一张能无限循环的 GIF 动图，不要视频、不要静态图、不要拼图」，否则可能给静态图。

其他模型没有 GIF 输出，只能出一张逐帧排好的拼图，再自己切帧拼成 GIF：

```text
一张用于循环 GIF 的逐帧拼图，共 [6] 帧，严格 [3] 列 × [2] 行，每格大小完全一样。
角色：[固定外形描述]。动作从[起始]逐步过渡到[结束]，第 [6] 帧能自然接回第 1 帧。
固定机位、固定背景、固定服装和比例；每帧动作变化清楚。无边框、无间距、无文字、无编号。
```

容易错：没写「回到起始姿势」，首尾会跳一下；背景和服装跟着动。

## 14 局部编辑

```text
只修改[哪个元素，用位置指明：画面左侧的扶手椅]：把它改成[新的样子：深绿色天鹅绒面料]。
保持不变：[人物身份和脸、姿势、其他物体、背景、机位、裁切、光线方向]。
新的部分要和原图的透视、阴影、色温、材质对得上。
不要添加任何其他元素或文字。
```

位置用文字说不清时（一堆相似物品里的某一个），用标注编辑：在图上圈出来，prompt 里点名「红圈里的…」。GPT Image 2.5 / 2.6 走 markup（圈画在另一张同尺寸的透明 PNG 上，不画在原图上），写法：

```text
把红圈里的[对象]改成[新的样子]。保持[它的形状、周围物品和画面其余部分]不变。成图里去掉红圈。
```

容易错：一轮改了好几处，漂了不知道是哪处带的——一轮只改一个维度，确认后再改下一处。「保持不变」那句别省，省了模型常会顺手改脸和背景；结果还在漂，下一轮把保持项再写一遍。要某块区域像素级不变，只能出图后自己合成回原图。

## 15 多参考图合成、同一人换场景

合成：

```text
图1 是人物身份参考，图2 是服装参考，图3 是场景参考。
生成一张[画幅][用途]：图1 的人穿着图2 的衣服，在图3 的场景里[做什么]。
保持图1 的脸部结构、肤色、发型和[能认出来的特征]；服装照图2 的款式、颜色和细节；场景照图3。
统一光照方向、色温、阴影和透视，看起来像同一张真实照片。
```

同一人换场景，先看构图变不变。

构图和姿势不变，只换背景或衣服——当编辑写，人留得最稳：

```text
编辑图1 这张[写实人像照片]：只换[背景 / 衣服]，人不变。
背景：[新场景]。衣服：[原来的] 换成 [新的：款式、颜色、面料、细节]。
保持不变：[她 / 他]的脸型、五官、肤色、表情、发型和[能认出来的特征]；姿势、景别、机位和裁切。
光线：[新场景的光]，脸上的明暗接近原图；人和背景的色温、阴影对得上，像同一张实拍。
不要美颜磨皮，画面里不要有文字。
```

要换姿势、换景别、换动作——当新图写，图1 只管这个人长什么样：

```text
图1 是人物参考。生成一张写实照片：这个人[在新场景里做什么]，穿[服装]。
保持[她 / 他]的五官、脸型和[能认出来的特征]，不要美颜。
[景别]，[光线]，[画幅]。画面里不要有文字。
```

容易错：用户只说了换背景和衣服，就别顺手给人设计新姿势、加道具；prompt 里的「图1、图2」要和上传顺序对上，交付时写明按什么顺序传；一张参考图只担一个角色。
