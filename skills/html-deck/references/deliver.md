# 交付：离线包、网站版、隐私

## 三个版本，三条边界

| 版本 | 给谁 | 带什么 | 不带什么 |
|---|---|---|---|
| 现场版（`讲稿/`） | 你自己放 | 全部：备注、本机嵌入页、私人数据 | — |
| 离线包（`交付/<名>.zip`） | 拷到别人电脑上放 | 讲稿、用到的文件、字体子集、备注、「怎么播放」 | 编辑模式 |
| 网站版（`交付/网站版/`） | 公开 | 页面和用到的文件、字体子集 | 备注、真名等替换掉的字、标了只在现场用的嵌入（换截图） |

离线包会拷到别人的电脑上，网站版谁都能看到，所以两者都按「对外」处理：**页面上看不到不等于文件里没有**。嵌入的本机页面、数据文件、页面里的数据快照都会被打包。

带哪些文件：讲稿直接引用的，加上嵌入网页和样式表再引用的（一层层往下找）；`嵌入/` 里没被引用的页面和草稿不带。嵌入页用脚本在运行时才加载的文件（`fetch('data.json')` 这类）找不到，要么改成直接引用，要么打包后解压在断网环境里打开那一页试一遍。指到讲稿目录外面的文件（`../`、绝对路径）会让打包停下。

## 交付顺序

```bash
python3 <SKILL_DIR>/scripts/check.py <项目>/讲稿                    # 溢出、缺文件、报错、断网
python3 <SKILL_DIR>/scripts/package.py <项目>/讲稿 --words 真名,公司名   # 离线包（内含隐私扫描）
python3 <SKILL_DIR>/scripts/website.py <项目>/讲稿 --replace 真名=网名 --desc "一句摘要"   # 网站版（内含隐私扫描）
```

- `--words`：除了路径、用户名、邮箱、手机号、密钥、IP，再让扫描找的词。开工时问过用户的真名、公司、项目代号都放进来
- 扫描发现就停下不出包。逐条看：该删的删、该换的换；确认没问题的原文片段写进 `--ignore` 文件放行，不要直接 `--force`
- 扫描只看得到文字。图片、视频、截图里的内容要人看：脚本会列出来，你用 Read 看一遍截图，再让用户过目

## 现场才用的东西怎么处理

本机页面、私人数据、要登录的系统，只放在现场版：

- 元素上标 `data-web-shot="嵌入/截图/x.png"`：网站版里整块换成这张截图（截图前把页面里的私人内容、用户名路径处理掉，并用 Read 看一遍）
- 标 `data-web="remove"`：网站版里整块删掉
- 离线包要外发时，这类嵌入同样要过一遍：嵌入页里有私人内容的，先做一份删干净的演示版再嵌，或者换成截图

## 网站版发布

`website.py` 只出静态目录，部署到哪个网站由用户自己的流程决定。网站会在页面顶上加站点顶栏的，加 `--top ".顶栏的选择器"`，幻灯片会缩到顶栏下面，按 F 全屏时把顶栏藏起来要在网站那边加一条 CSS：`html:fullscreen .顶栏 { display: none }`。网站有自己的脚本和样式注入的，发布前在本地按网站的方式起一遍，看顶栏、按钮有没有和讲稿的类名撞上。

## 拿到别的电脑上放之前

- 用 Chrome 或 Edge；在那台电脑上提前打开翻一遍
- 字体已经打进包里；没下载成功时脚本会提示，联网重打
- 视频用 H.264 的 mp4；静音循环播放
- 断网能放：在线页配了备用截图的会自动换（check.py 会列出没配截图的页）
- 翻页笔、投影比例（16:9）、双屏的演讲者视图，提前试
- 包发出去以后又改了，或者发现包里有不该带的东西：重打一份，请对方删掉旧包换新的
