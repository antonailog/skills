# 放映：按键、翻页笔、演讲者视图、动效

## 按键

| 按键 | 作用 |
|---|---|
| → ↓ PageDown 空格 回车 | 下一步（先走本页的分步，再切页签，最后翻页） |
| ← ↑ PageUp 退格 | 上一步 |
| Home / End | 第一页 / 最后一页 |
| F，或 F5 | 全屏；Esc 退出 |
| O | 总览：所有页的缩略图，点哪页跳哪页，Esc 关 |
| B 或 句号 / W | 黑屏 / 白屏，再按任意翻页键恢复（不会顺带翻页） |
| N | 备注面板（带计时） |
| P | 打开演讲者视图；再按一次关掉 |
| T | 计时归零 |

网址后面的 `#3` 就是第 3 页，刷新停在原处。

## 翻页笔

常见翻页笔发的是 PageDown / PageUp（有的发方向键），「开始放映」键发 F5 或 Shift+F5，「黑屏」键发句号或 B，全都接好了。上台前用翻页笔从头按到尾试一遍；不同牌子按键不同，不灵时让用户告诉你它发的是什么键。

## 演讲者视图

按 P 打开一个新窗口：左边当前页，右边下一页和备注，底下计时和当前时间。两个窗口翻页和黑屏同步，翻页、B / W 黑白屏在哪个窗口按都行（本地文件直接打开也能用）；F 全屏、O 总览只作用在按键的那个窗口。黑屏、白屏时演讲者视图自己不黑，底栏标出「观众屏幕：黑屏」，备注和计时照常看。

关掉演讲者视图：在演讲者窗口里按 Esc 或 P，或在主窗口里再按一次 P；直接关窗口（⌘W）也行，主窗口接着放。

双屏用法：笔记本屏幕放演讲者视图；讲稿窗口拖到投影上，按 F 全屏。浏览器拦了弹窗时，在地址栏右边允许弹出窗口。

## 动效

- **翻页**：每套风格有默认（瑞士网格、编辑书卷淡入；暗场发布会、新野兽派推移）。整篇换：`<html data-transition="push">`，`fade` / `push` / `none`
- **分步**：出现时淡入加轻微上移；section 上加 `data-focus`，前面的条目变淡、突出当前这条
- **数据**：大数字（`.stat .v` 和带 `data-count` 的元素，里面只有一个数字时）出现时从 0 滚到目标；柱子长出来、折线画出来、环形转出来
- 系统开了「减少动态效果」时，这些都自动关掉，直接显示最终状态
- 动效为讲清楚服务：同一页不要叠太多，数字滚动和图表生长已经够了；不要给每页加花样
