**看图时查**
1. **标题逐字对**：重点看「第一杯」的「杯」和「桂花」两个字，中文常会写错或少一笔；再看两行是不是按「秋天的第一杯 / 桂花拿铁」断开的。
2. **小字逐字对**：「11月15日」「50 杯」这两个数字最容易被改成别的；再看「起」和「限量」有没有漏掉。
3. **桂花像不像桂花**：容易被画成大片的黄色花瓣，或者像菊花、迎春花。要的是米粒大、一簇簇的小金花。
4. **杯子和杯碟上有没有多出来的字**：模型常自己加英文店名或「LATTE」这种字样。
