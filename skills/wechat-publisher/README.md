# wechat-publisher

Markdown 推成公众号草稿

## 要解决的问题

作者的公众号文章在本地用 Markdown 写。发到公众号前，每篇都要压缩图片、上传换成线上链接，把 Markdown 按主题渲染成带样式的正文，再放进草稿箱。这个 Skill 管写作流程的最后一段：从生成发布版一路做到推进草稿箱，顺带写好推广文案、给出发布时间建议。

## 运行方式

![wechat-publisher 结构图](../../docs/diagrams/wechat-publisher.jpg)

压缩上传图片、生成发布版、推送草稿箱由脚本完成，校对、选主题、写推广文案由 Claude 做。校对发现的问题先报给用户，用户确认后才往下发；选了几个主题，就各出一篇草稿。推进草稿箱后，Claude 按文章类型给出发布时段和分批投放建议，最后提交到文章仓库。

## 关键设计

- **只推到草稿箱，不直接发布**：正式发布前，用户要在公众号后台预览确认
- **排版用左对齐，不用两端对齐**：两端对齐会把一行只有两三个字的句子撑满
- **发布和投放分开**：文章可以提前发，投放等目标读者最活跃的时段，渠道分几波用，不在同一时间消耗完
- **推广文案像跟朋友说话**：写清做了什么、参考了什么、解决了什么、对谁有用，不用营销腔
- **凭据一律从环境变量读**：仓库是公开的，不放任何密钥

## 其他

- 前提：Python 3 和 oss2；Node.js 和全局安装的 `@wenyan-md/mcp`；macOS 自带的 `sips` 压图；环境变量 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、`OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`、`OSS_BUCKET`，`OSS_ENDPOINT` 可选
- 注意：`prepare_article.py` 会给所有图片加 `{width=340}`，横向插画要手动去掉才能铺满，竖图和 UI 截图保留
- 注意：首次发布可能报 IP 白名单错误（40164），要在公众号后台把当前 IP 加进白名单
- 注意：没在正文里引用的图片（例如 16:9 封面）要单独上传 OSS
