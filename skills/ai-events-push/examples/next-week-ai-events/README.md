# 示范：挑好的五场活动 → 一张群推送海报和一段群消息

日期：2026-11-03 · 使用的 Skill：ai-events-push

给 ai-events-push 五个活动名，拿回一张按城市分区的长海报和一段能直接复制进微信群的文字。五场活动都在「国内AI活动追踪」网站（antonailog.com/more/ai-events/）上：北京三场（百度世界 2026、Rebuild 2026 中国企业 AI 大会、GOTC 2026 全球开源技术峰会），上海一场（源点 ORIGIN 上海站），线上一场（China AI Infra Day）。

## 给了什么

原样见 [input/请求.md](input/请求.md)：一句话，五个活动名，说明是下周（11/9–11/15）的推荐。

## 用户会怎么说

在 Claude Code 里说一句：

> 下周的活动推荐出一版，这几场我觉得不错：百度世界 2026、GOTC 2026 全球开源技术峰会、Rebuild 2026 中国企业 AI 大会、源点 ORIGIN 上海站、China AI Infra Day。

贴一张网站截图、丢几个活动链接、转一张别人发来的活动海报，说「做个推送」「这几个活动发群里」，都会触发 ai-events-push。之后按 Skill 的流程走：认活动 → 起草海报数据 → 核实 → 写文字 → 出海报 → 核链接 → 交稿。

这次是示范，产物都写在本目录，没有改网站，也没有发群。

## 交出了什么

| 文件 | 是什么 |
|---|---|
| [output/海报.png](output/海报.png) | 直接发群的长海报：北京、上海、线上三个分区，每场一张门票，左边宣传图，右边日期钟点、名称、地点、主办方、三行介绍，右侧副券写价格 |
| [output/文案.md](output/文案.md) | 两条横线之间是要发的群消息，每场一段标准介绍加「详情」「报名」两个链接；下面是核实记录：每条事实取自哪里、没写进去的内容、网站上发现的错 |
| [output/活动.json](output/活动.json) | 海报的数据，改了重跑 `make_poster.py` 就能重出 |

## 过程里值得一看的地方

- **网站上的信息不全信**：核实时以活动方的海报和报名页为准，查出网站上五处要修的地方（比如一场大会网站写「免费」，实际免费票只开放展区、主会是 2688 元的双日票），都记进了 文案.md 的核实记录，网站本身按 Skill 的规矩先不动，等作者确认。
- **读不到的页面换路子**：活动方的公众号文章被微信验证墙挡住，就读网站存下的活动原文和海报原图；活动行页面要跑 JS 才显示票价，就在浏览器里打开再读；报名链接从海报二维码里解出来。
- **查不到的不编**：有一场的官网和报名表都没写费用，票面印「费用未写」，文字写「以报名页为准」。

## 代确认的门禁

Skill 里要作者拍板的地方，这次一律按默认：

- **网站上的错要不要修**：默认不改网站，只记进核实记录。
- **有免费档也有付费档的票价怎么印**：副券印付费那档（「¥2688」「¥398起」），免费那档写进介绍。
