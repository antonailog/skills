# 调研确认单

> 由协调者在 S1 填写，落盘为 `research_notes/<课题>/00-intake.md`。先从 query 与用户材料填，填不出且最影响产出的项才拿去问（一次 ≤3 问）。读者三项（是谁、要做什么决定、能投入多少）决定报告的「如果你是 X」、结论表阈值和成本账的规模，填不出时优先问它们。

| 项 | 值 | 来源（query / 材料 / 用户回答 / 默认） |
|---|---|---|
| 课题名（3—6 词） | | |
| 对象类型 | product / industry / company / ai-tool / generic | |
| 对象列表（1—6 个） | | |
| 要回答的问题（1—3 条） | | |
| 问题类型 | 描述现状 / 诊断 / 预测 / 建议 | |
| 时间口径 | 默认：最近 12 个月，历史背景可上溯 | |
| 地域 / 语言口径 | 默认：中英文公开来源 | |
| 读者是谁 | 例如：独立开发者 / 投资人 / 产品经理；默认：用户本人 | |
| 读完要做什么决定 | 例如：要不要做、从哪切入、选哪个；默认：从「要回答的问题」推出 | |
| 能投入多少（可选） | 时间或钱；不填就按「小团队、几个月」写成本账与行动建议 | |
| 用户已给材料 | 路径 / 链接 | |
| 需要原帖级口碑？ | 是（启用本机爬虫）/ 否 | |
| 已知查不到或封顶"中"的数字 | 流量 / 收入 / 下载量等 | |
| 是否经用户确认 | 是 / 否（非交互或按默认） | |
