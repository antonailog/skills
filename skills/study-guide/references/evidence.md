# 补证据、收实物

第 3 步读。`<skill>` 指本 skill 的目录，命令都在学习指南目录下跑。

## 找回引用链接

材料带内部引用标记、链接丢了时（inventory 的「引用标记」> 0）：

1. `extract_cites.py` 备料
2. 派子 agent 按材料分批找原链接，写进 `links/<材料名>.json`（字段见 merge_sources.py 开头）。网页搜索有额度，一个子 agent 别派太多条，用光了就分批续
3. `merge_sources.py` 并进 `sources.json`

材料里的引用有几百条、正文只用到其中一部分时，逐条找回成本很高。可以换个顺序：先写正文，再把正文真正用到的论断按主题分成几组，各派一个子 agent 回原网页核对，每条交回 `status`（核实 / 有出入 / 找不到）、`url`、原文摘句 `quote`；有出入的按原文改正文，结果合并成 `sources.json`，核对记录写进 `核对.md`。这样只核正文用到的，也顺带完成了「核对关键论断」。

## 核对关键论断

正文要用的数字、日期、产品功能、原话，对着原网页核一遍。

## 补薄弱的证据

提纲里记下的证据薄的地方，自己联网检索补齐。查到的来源手写进 `sources.json`，同样对着原网页核一遍。

## 收外部对象的实物

- 登记进 `sites.json`、`videos.json`，跑 `collect_refs.py` 收截图、封面、能嵌的视频
- 字体、作品这类，登记它的样张页或展示页
- 作品图优先找开放获取的馆藏页（芝加哥艺术博物馆、哈佛艺术博物馆等）：有的博物馆对脚本只返回人机验证页，有的藏品因为版权不公开图片。找不到能用的图就只留链接；需要让读者看出特征时，用代码画一张特征示意，并在图注里写明不是原作
- 要看的图在页面中部、首屏被 Cookie 弹窗挡住时，用 `shot` 的 `element` 只截那个元素（components.md「截图画廊」）
- 首屏是加载动画、要看的部分在下方时，用 `shot` 调整（components.md「截图画廊」）
- 截到的逐张看一眼，和正文说的不是一个东西的删掉重找
- 关键数据（年份、成绩、价格）要有出处
- 跑 `fetch_icons.py` 下载来源网站的图标（引用浮窗和来源列表用）；没拿到的页面上显示通用图标，不用补

## 检查链接

跑 `check_links.py` 逐个打开正文用到的链接。「确定坏了」的换掉，「需要人工确认」的自己开一次。

换链接分两种情况：

- 同一份来源，只是换了地址：材料引用（`材料名-n`）改 `links/<材料名>.json` 再跑 `merge_sources.py`，直接改 sources.json 会在下次合并时被覆盖；手写的来源直接改 sources.json
- 换成另一份来源：sources.json 加一个新 id，guide.md 里的 `[[旧 id]]` 改成它

核对结果、没找回的、打不开的写进 `核对.md`，不上页面。
