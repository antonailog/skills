# 提纲：视觉设计入门

## 范围

来自 0-说明.md 和 1-prompt.md：给没系统学过设计的人补设计学科的底子（思维、排布、视觉元素、流派风格、三类载体、学习材料），AI 协作不在范围内。主题涉及方法（诊断和修改一个画面），所以写方法论：一套诊断顺序、评审说法、几种低成本测试，和一个从头走一遍的示范。

材料对应：报告 1 → ① 设计思维和评审；2 → ② 构图版式；3 → ③ 色彩字体图像；6 → ④ 流派风格；4 → ⑤ 三类载体；5 → ⑥ 学习材料。

## 读者任务

读完能说清：
- 设计在解决什么问题，「好看」和「好设计」是什么关系
- 设计师看一个画面的先后顺序，以及每一层在看什么
- 排布、视觉元素、风格、载体各管什么；哪些说法有实验支撑，哪些是行业经验
- 用准确的风格名称描述想要的效果

读完能做成：
- 拿到一个网页、卡片或海报，按顺序找出问题，说成「现象 + 对目标的影响 + 修改方向」
- 用五秒、灰度、缩略图、远近距离、删除这几种测试验证修改有没有用
- 知道接下来四周读什么、看什么、怎么练眼力

## 叙事主线

从「能感觉好不好看，却说不清为什么」出发。第一个关键判断是：设计处理的是关系（信息和人、信息之间、信息和下一步行动），「好看」只是其中一个变量，所以评价要从目标开始。第二个判断是：设计师看画面有固定的先后，目标 → 信息 → 路径 → 关系 → 表达 → 一致性 → 风险，越靠前的问题影响越大，这个顺序就是全文的骨架。后面各章沿着它补工具：关系层是排布原则（证据最强）；表达层是色彩、字体、图像、质感（有硬标准，也有经验）；风格是表达层的成套组合，学会它的名字才能描述和选择；载体决定同一套原则在网页、卡片、海报里的权重。最后把这些串成可执行的工作方法（流程、评审、测试），用一场活动的海报、分享卡和报名页从头示范，落到怎么继续学和练眼力。

## 展示设想

- 示范和对比图一律用真实 HTML 排出来再截图（样章的产品首屏就是这样做的），不用生图模型，因为生图容易把字写错
- 一：五组关系用表格；经典主张用表格（主张、提出者、核心论点、今天的适用范围）
- 二：观察顺序用一张流程图，把每一层连到后面对应的章；「模糊说法 → 可讨论的说法」用两列表格
- 四：咖啡卡片的两套方案排成两张真卡片并排；色板和对比度用表格
- 五：讲座海报的三种风格排成三张真海报并排；历史运动用画廊
- 六：三类载体对比用表格；报名页、分享卡、海报的实际版式放在八里
- 七：工作流程用流程图；五种测试用表格（测什么、怎么做、多久、通过标准）
- 八：海报改版前后两张真海报，加阅读路径图；同一活动的三个载体并排
- 九：学习先后用流程图；四周安排用表格

## 样章

第三章「排布的基本原则」：证据最密、组件最多（表格、画廊、流程图、改版前后对比），最能看出证据的写法和版式对不对。
