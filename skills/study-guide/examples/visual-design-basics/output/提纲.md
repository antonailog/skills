# 提纲：视觉设计基础

## 读者任务

读者常做网页、信息卡片、海报，能感觉好不好看，但说不清差在哪、不知道怎么改。读完能说清：

1. 设计在解决什么问题，「好设计」和「好看」是什么关系；设计师看一个画面的先后顺序。
2. 「排」的规律：分组、层级、视线、留白、网格分别是什么，哪些有研究支撑、哪些只是经验。
3. 「选」的规律：颜色按角色分、对比度的硬标准、字体的气质、图像和质感怎么保持统一。
4. 常见流派和风格的名字、样子、适用场合，能用准确的词描述想要的效果。
5. 网页、卡片、海报三种载体的阅读条件不同，设计重点也不同。
6. 接下来按什么顺序学、去哪里看好作品、用什么工具、怎么练眼力。

**写方法论**。判断依据：0-说明.md 写明用途是「系统学一遍设计思路，辅助用 Agent 做好网页、卡片、海报」，读者会动手；6 条 prompt 每条都要求「拿一个常见场景从头示范一遍」。所以还要让读者能做成：拿到一张画面，按固定顺序诊断，说出问题并给出修改方向；判断一个方案对不对。方法论落在第二章（诊断顺序和评语写法）、第七章（完整示范）和文末检查清单。

## 叙事主线

从「设计处理的是关系，不是单个元素好不好看」出发：先讲设计师看画面的顺序（目标 → 信息 → 路径 → 关系 → 表达 → 一致性 → 风险），这条顺序是全篇的骨架。接着沿着这条顺序往下拆：「关系」这一层靠排布解决（分组、层级、视线、留白、网格，按证据强弱讲）；「表达」这一层靠视觉元素和风格解决（颜色、字体、图像、质感，再到流派和风格这套更大的「表达词汇」）；「情境」决定同一套原则在网页、卡片、海报上的权重不同。然后用一张活动海报从头走一遍诊断和修改，把前面所有判断串起来。最后落到怎么练眼力、接着学什么。

关键判断：①先判断画面有没有解决正确的问题，再讨论表现手法；②层级和分组是目标，网格、留白、对齐是手段；③感知规律里有实验支撑的（接近、共同区域、显著性和任务共同决定注意）和行业经验（Z 型、视觉重量、8px）要分开对待；④颜色先按角色分、再谈比例，对比度有硬标准；⑤风格分三个层次，混搭靠「一个管结构、一个管性格、一个管交互」；⑥练眼力要有任务和反馈，不靠收藏。

### 裁决

| 冲突或易混 | 裁决 | 理由 |
|---|---|---|
| F 型扫描是不是网页模板 | 不是。F 型只出现在缺少小标题和格式的大段文字页，是「没有强线索时的默认扫描」 | 回原文核过：NN/g Pernice 2017-11-12（2026-08 复审）原文写 F 型是 no strong cues 时的默认模式，列出 layer-cake、spotted、marking、bypassing、commitment 等其他模式。见核对.md |
| Z 型构图 | 当构图启发用，不当阅读定律 | 2 指出缺少同等级眼动证据；UEyes 显示载体不同注视模式不同 |
| 60/30/10 | 当起步模板，网页优先按颜色角色（surface、primary、on-primary…）分配 | 3 自己标为经验规则；Material 3 color roles 是成体系做法，第 3 步核原页 |
| 设计评审先谈问题还是先谈画面 | 先确认问题，再评方案，最后评实现 | 回原文核过：Google Design「Going beyond the surface」三阶段（problem / solution / implementation），且写明没有共识就会陷入菜单、字体这类表面细节的争论 |
| Design Thinking 和做好画面的关系 | 它管「解决什么问题、怎么探索验证」，不训练视觉能力 | 1 引 Kimbell 2011 的批评和 2023 年设计方法有效性综述；放在二章作为术语澄清，不当主线 |
| 弱交互提示（超扁平）的代价 | 写成「71 人眼动实验，弱提示多 22% 时间、25% 注视；一组页面 50% vs 86%」 | 回原文核过：NN/g Kate Moran 2017-09-03，数字一致 |
| 共同区域能压过接近 | 写成「加框、连线这类线索可以压过单纯的距离」 | Palmer 1992 原文摘要拿不到；Palmer & Rock 连通性和 Wagemans 2012 综述支持「连通/区域线索强于接近」，正文用这个较保守的说法 |
| 「新表现主义」是不是一个流派 | 不当独立运动写，归到表现性设计、反设计、后数字、Neobrutalism | 6 的判断，本篇沿用 |
| 小红书、微信有没有统一图片尺寸 | 写「公开帮助页没有统一像素尺寸，以 App 当前裁切预览为准」，并写明查的时间 | 4 的检索结论；第 3 步复核 |
