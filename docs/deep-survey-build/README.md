跑脚本单测：

```bash
python3 -m unittest discover -s 3_评测/单测 -v
```

单测读同一仓库里的 `skills/deep-survey`，要测别处的副本时设环境变量 `DEEP_SURVEY_SKILL`。

有几类文件只留在作者本机、不进仓库（见本目录 `.gitignore`）：个人信息流的摘要、本机历史调研的样本分析、私有系统的接入方案，以及每次大改前的 skill 快照和全部图表样张。文中提到它们时，读者看不到原文。
