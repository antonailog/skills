## 目标

做一个调研 skill：给一个产品、行业、公司或 AI 工具，产出一份**外行读得懂、读完能做决定**的深度报告。

报告要达到三个效果（用户 2026-10-10 定）：

1. **清晰易读**：结构一眼能懂，每段只讲一件事。
2. **真实有用**：信息可信，按认知顺序展开，读者能带走关键知识。
3. **适合传播**：没有阅读压力，愿意转给别人。

## 想法池（已讨论、已采纳方向，实施状态见 todo）

完整论证见 `1_方案/v4改版分析-2026-10-10.md`。

| # | 想法 | 来自 |
|---|---|---|
| I1 | **分层阅读**：1 分钟版、10 分钟版、全文；只读判断句标题、加粗首句和图表，也能讲完故事 | 「篇幅不限」与「没有阅读压力」的调和 |
| I2 | **导语改成「一分钟看懂」**：一句话定义 + 一个反差（≤2 个数字）+ 五条要点（每条 ≤40 字）+ 读法导航 | v3 导语问题分析 |
| I3 | **图文分工判据**：比较、看形状、看结构用图或表；跟着推理走用文字；感受用引语卡；没有数据不画数据图 | 用户意见 1 + 分析 |
| I4 | **图形化形式清单** 20 种，含 v3 完全缺失的产品截图 | 用户意见 2 |
| I5 | **出图实现**：数据图走「数据文件 → 脚本 → SVG / PNG」且每个数值带来源；结构图用 Mermaid；截图走浏览器；封面走 codex 生图；生图模型不画数据图 | 用户意见 3 |
| I6 | ~~两个版本~~：用户决定只出 md，不主动转换 | 已否决 |
| I7 | **短段落**：≤3 句、≤100 字；小节 = 加粗结论 + 证据要点；每 400—600 字一个非文字元素 | 用户意见 5 |
| I8 | **信息需求清单 + 覆盖率门禁 + 最多三轮定向补研 + 覆盖率报表** | 用户意见 6、8 |
| I9 | 消费类产品按市场拆研究员（中国 / 海外）；用户原声默认开本机抓取；403 退到浏览器 | 用户意见 6 |
| I10 | **竞品档案表**：功能、价格、规模、收入、融资、口碑、合规七张固定字段表；研究员产出结构化数据，表和图从数据渲染 | 用户意见 7 |
| I11 | **搜索规划表**：每类信息需求对应搜索方向、优先来源、最低证据量；中英文查询词、`site:` 定向；摘要不算证据；PDF 读全文 | 用户意见 8 |
| I12 | **分析模块**：归纳、对比归因、机制模型、反直觉、二阶推演；每条注明依据章节 | 用户意见 9 |
| I13 | 「还不知道的」升级为问题清单，作为下一轮补研的输入 | 用户意见 10 |
| I14 | 「带走的知识」并进「一分钟看懂」 | 用户 v4 决定 1 |
| I15 | **图表主题系统**：clean / 杂志 / 瑞士三个家族 11 套主题；不设默认，按文档风格自选，蓝橙色系优先；配色取自 guizang-ppt-skill | 用户要求图表更好看、风格不写死 |
| I16 | **导引图 + 推荐阅读**：一分钟看懂里一张模块导引 SVG；文末 5—10 条推荐信源带推荐原因 | 用户 10-10 |
