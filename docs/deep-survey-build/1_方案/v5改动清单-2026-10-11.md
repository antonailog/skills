## 知乎密钥（10-11 已完成，接口实测可用）

1. 打开 https://developer.zhihu.com/ ，用知乎账号注册，在个人中心生成 Access Secret。
2. 在终端运行下面几行。密钥只存在你本机，权限只有你可读，不进 skill、报告和笔记：

```bash
mkdir -p ~/.config/deep-survey
touch ~/.config/deep-survey/secrets.env && chmod 600 ~/.config/deep-survey/secrets.env
read -s "k?粘贴知乎 Access Secret 后回车："; echo
printf 'ZHIHU_ACCESS_SECRET=%s\n' "$k" >> ~/.config/deep-survey/secrets.env; unset k
```

不做也能开工：知乎会降级为只拿标题和链接。脚本先读环境变量，再读这个文件；以后 Info2Action 的密钥也放这里。
