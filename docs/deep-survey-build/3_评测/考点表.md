# deep-survey 报告评分入口

现行唯一评分标准是 [report-quality-policy.md](../../../skills/deep-survey/references/report-quality-policy.md)，版本 1.0.0，2026-10-14 冻结。版本验收用两名独立评审，分别保留八维分数、事实核验账本、严重问题、暂定状态和证据。质量不按格式数量、篇幅或 token 评分；原始分数不得为新版本胜出而回改。

脚本机械检查与质量评分分开。历史报告仍按其评估当时的标准理解；下面旧表仅作历史记录，不能与现行 policy 混用。本轮独立评分保存在 `report-quality-2026-10-14/`。

## 历史考点表 v5（不再生效）
