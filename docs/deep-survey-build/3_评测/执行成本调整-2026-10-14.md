# 执行成本调整：实现与验证

用户已批准 AIE 真实运行诊断后的调整。本轮修改现有 Skill，不重新做 AIE 联网调研，不改变模型与推理档位，不提交或发布仓库。

## 基线与问题

2026-10-14 AIE 上海参会决策实际用时 51 分 15 秒。主会话及五个工作 agent 共 233 次模型响应：缓存输入 22,455,040、非缓存输入 573,567、输出 116,228，累计 23,144,835 token。平台审批记录另计；推理输出包含在输出中，不能重复相加。主会话占累计处理量约 43.4%。这些是观察值，不是浪费或账单金额。

固定的研究 → 长备忘 → 核对 → 写作 → 冷读 → 返修，叠加整段历史继承、频繁状态检查、图表依赖失败后另写绘图代码，以及来源重排交接缺口，增加了投入。关键查证和独立冷读有实际价值，继续保留。

## 本轮改动

| 问题 | 调整 | 保留的质量要求 |
|---|---|---|
| 所有课题走同一长流程 | 具体决策默认一到两人研究、主会话综合成稿、一次冷读；完整专题才交短备忘 | 理解材料的人写报告，核心问题有正面回答 |
| 分工重叠、文档重复 | 独占证据块，每人一份笔记，已有发现按路径复用 | 因果、反面材料和未知仍需表达 |
| 只追覆盖，缺乏全局控制 | 默认共享检索预算 30 / 60 次，含主笔补查；仅关键缺口可加一批，最多原预算三分之一 | 到限不猜，交条件性结论和缺口；预算不是配额 |
| 协调占用大 | agent 最小上下文、按完成事件推进，不反复查文件大小 | 失败和会改变决定的缺口仍及时处理 |
| 图表固定成本 | 按表达价值制作，零图正常，缺依赖用表格或文字 | 已有图仍检查数据口径和可读性 |
| 来源映射错位 | CSV 保留 URL；最终自动生成编号与链接，同步 JSON/Markdown；验证同号同页 | 原件保留，错误映射拒绝改写，重跑稳定 |

主文件由 4,151 字符缩至约 3,500 字符，新增控制替换旧流程，未堆叠新的角色或运行框架。完整专题仍保留同一主笔理解与写作的连续性。新深度和预算更新 10-12 的历史决定，以本次用户批准为准。

## 实际运行的验证

1. **回归先复现**：新增 8 个引用管线用例在旧脚本上有 7 个失败，另 1 个 dry-run 用例原本通过。
2. **完整脚本测试**：现有 22 个加新增 9 个，共 31 个全部通过。只更新旧用例中本轮有意改变的输出预期：正文引用变为可点击链接、CSV 保留 URL。
3. **新用例覆盖**：编号和 URL 对应、来源 JSON/Markdown 同步、旧 CSV 迁移、原件备份、幂等重跑、dry-run 不写文件、同页合并、图表旧号与新号碰撞、引用错配拦截、重建保留旧号并追加新源、URL 跟踪参数兼容。
4. **真实报告离线回归**：复制 AIE 重排前报告与 34 条旧来源，在临时目录运行新交付脚本。报告实际引用的 22 条来源自动重排为 1—22、生成链接并同步来源表；检查为 0 错误、0 警告。原 AIE 报告未改动。这个检查验证引用交付，不等于新流程完整实跑。
5. **Skill 结构体检**：0 错误。保留仓库现有 README，因此仍有一个“Skill 内存在 README”的提示；该文件已同步为当前说明，没有为消除提示删除已有文档。

测试环境：本机 Python 3.14（已有 Matplotlib 3.10.8），MPLCONFIGDIR 指向可写临时目录。Python 3.13 和捆绑运行时缺 Matplotlib 时，原有四个图表测试会因依赖失败；切到现有可用环境后完整通过，未安装或修改依赖。

复跑脚本测试：

```bash
python3 -m unittest discover -s docs/deep-survey-build/3_评测/单测 -v
```

使用已具备 Matplotlib 的 Python；图形缓存目录须可写。回归支持 `DEEP_SURVEY_SKILL` 指向快照，原有测试入口不变。

## 规则走查（非模型路由实测）

| 输入 | 应走路径 | 检查点 |
|---|---|---|
| AIE 上海值不值得去，技术学习与交流并重，对照 Maker 上海 | 具体决策，两块证据 | 主会话直接综合；价格、条款、真实议程和对照不能漏；无需长备忘或收益流程图 |
| 调研两个 AI 搜索 API，给我项目选一个 | 具体决策 | 同口径效果、成本和接入限制；不扩成行业百科 |
| 深度调研某工具是否值得接入现有小项目 | 具体决策 | 不因“深度”二字自动升级；必要接口机制仍解释 |
| 系统研究 AI 陪伴行业的格局、付费行为和商业机制 | 完整专题 | 一位主笔综合全部材料，保留短备忘与独立冷读 |
| 研究一家公司的技术、业务、竞争与组织风险，供长期跟踪 | 完整专题 | 跨问题因果需要展开，按证据块分工 |
| 把已有报告压成五条要点 / 分析 Skill 为什么运行慢 | 不启动调研管线 | 分别直接总结 / 诊断；不因对象含 AI 或 Skill 自动重新研究 |

以上按指令静态走查，不写成触发率、盲评结果或耗时实测。
