## 首版保留的边界

“仅原样下载”在 test 集 3 次里有 2 次读取 Skill，随后均正确退出整理流程。指标严格按读取计为误触发；不利用这一个测试题继续改 description。它不代表执行了摘要或远端写入。

两份合成样本各条件只生成一次，独立评委的重复评分不等于生成多次；不能据此证明长期稳定性或完整外部工具流程。人工抽检的 4 项已获用户明确确认符合预期。

## 三个最高价值的后续方向

1. 下一期真实节目按本 Skill 完整跑一遍下载、图文、原生画板与回读；覆盖现有用户画板手改，不为评测修改本期已验收文档。
2. 增加机制解释和研究访谈样本，特意覆盖来源截断、数值冲突、图片缺失、没有完整资格条件等情况；替换只测简单字段存在的弱考点。
3. 测试更精简的按需引用与局部修订路径，减少重复读工具说明和重复生成检查代码；保留真实来源、用户内容保护和可编辑验收要求。

这些是后续迭代候选，不是当前交付缺失项。自动同步、付费处理和新外部服务均未作为本次内容扩展。

## v2 · 2026-10-21 至 2026-10-22：按《知识总结设计原则》重构并用两期真材料跑通

**为什么改**：用户要所有「外部知识转文字总结」的模块遵守同一套设计原则，先拿本 skill 落地。原则文档由维护者另行维护（不随仓库发布），本 skill 按「构建时参考、包内自带副本」的约定吸收其中适用部分。改前快照：[archive-v1-2026-10-21](archive-v1-2026-10-21/)。

**改了什么**

| 方面 | v1 | v2 |
|---|---|---|
| 页面结构 | 总结／关键要点／总览三部分 | 播客信息（两列信息表）→ 关键要点（关键内容、骨架图、总结图）→ AI 总结（按问题组织的正文单元）→ 问答（答案直接展示）→ 个人思考 → 延伸资料 → 原始资料附件 |
| 门禁 | 内容方案工作稿 | 结构提纲门禁：一级结构与每支一句判断先过目 |
| 查漏 | 质量自检 | 题从转写出、干净执行者只拿正文答（盲测）；挑有价值的问答对上页 |
| 强调 | 加粗、少量高亮、下划线标条件 | 加粗＝单元结论短语；下划线＝段内关键词；高亮＝全文极少数；斜体＝边界与口径 |
| 图 | 每期手写 SVG，配色每期自定 | 图稿驱动：`_shared/figkit` 渲染 + 自动校验；配色取 beautiful-feishu-whiteboard 主题（默认 Editorial Forest）；箭头改原生连接器 |
| 脚本 | source_manifest、audit_document | 新增 fetch_episode、md_to_feishu_xml、write_boards、link_and_check、make_figure |
| 术语 | 无规定 | 专业术语首次出现就近解释 |

**被否的版本**（详见维护者讨论记录）：自造配色三轮都被否（OKLCH 角色表、浅色单色、编辑式蓝橙），原因是卡面大面积填色、层级靠颜色而非灰阶与字重；改为原样采用 beautiful-feishu-whiteboard 主题。边界句整句下划线被否，改为下划线只标关键词、边界用斜体。
