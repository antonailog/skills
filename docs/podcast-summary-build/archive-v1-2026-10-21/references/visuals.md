# 绘图与可编辑画板

## 先选关系，再选视觉风格

| 信息关系 | 优先形式 | 图内直接展示 |
|---|---|---|
| 叙事发展、认识变化 | 时间线、事件／观点双线、选择分支 | 处境、事件、决定、结果、转折原因 |
| 多人观点或两种方案 | 对照、取舍矩阵 | 主张、前提、证据、代价；不人为评胜负 |
| 过程与方法 | 流程、步骤、决策树 | 输入、动作、真实条件、结果、反馈或失败 |
| 因果影响 | 有条件的因果链 | 中间机制、方向、条件、不确定性 |
| 多项约束 | 条件汇合图 | 每项限制、共同作用、同一适用地区与对象 |
| 层级与组成 | 关系树、分层图 | 归属；不要用上下级伪装因果 |
| 数量与趋势 | 条形、折线、同口径小多图 | 单位、时点、分母、坐标与来源 |
| 整体与部分 | 堆叠条形、组成图 | 可加总的同一整体、互斥部分与比例 |

箭头应能读成“需要／下一步／影响／取决于”等关系。只有同属一个对象、地区和时期的限制才汇合；不同城市的举例分开列。没有精确数据时用有标签的示意图，不生成虚构比例、曲线或精确坐标。

## 可选风格

风格服务内容，不让所有节目都变成六张等大的卡片。优先沿用用户已认可的风格，结构随本期变化。

| 方向 | 合适内容 | 画法 |
|---|---|---|
| 编辑式信息图 | 讨论、社会议题、多维取舍 | 米白底、深绿结构、粉色强调；大小不同的模块与关系连线 |
| 叙事时间线 | 人物、历史、经历 | 柔和纸色、时间主线、转折重点、少量分支；事件与认识区分 |
| 机制流程图 | 技术、系统、方法 | 浅背景、冷色层级、明确输入输出、边界和反馈路径 |
| 证据与数据板 | 研究、案例、比较 | 中性背景、对齐的坐标与标注、强调色突出差异，保留不确定性 |
| 判断与取舍图 | 决策讨论 | 对照列、条件分支与成本说明；颜色辅助区分而非唯一信息载体 |

同一页保持字体、色义、线条一致，局部图可采用不同关系结构。模块多少、画布长宽和配色都不固定。

## 三类图分工

- **整期总览**：中心问题、所有实质模块和主要关系，模块内部有关键细节与必要数据；能够独立说明整期。
- **详细思维导图**：调用 book-to-mindmap 的结构、真源与导出方法。判断做枝干，原因、例子、数值、条件做可见子节点；重要内容不只存在 notes。单集通常一张画布。
- **局部详图**：某个模块的机制、推导、对比或分支展开。图就在模块旁；不得因为有详图就把总览该模块只剩一个标题。

先做实质主题 → 图中落点的覆盖表，再检查每个重要数字、边界、分歧。数量多或层级深本身不证明覆盖；检查读者能否据图回答问题。

## SVG 与原生转换

保留 SVG 文字、矢量图形和连接关系；在支持转换的工具里转成飞书原生节点。先阅读当前 `lark-cli skills read lark-whiteboard` 及其引用，使用当前支持的转换和写入接口。不要凭猜测构造接口，或把一张大图片放到画板上宣称可编辑。

参考公开项目 [beautiful-feishu-whiteboard](https://github.com/zarazhangrui/beautiful-feishu-whiteboard) 的版式与 SVG 方法；实际接口语法以当前工具文档为准。按工具技能要求分工，主线程仍核对内容、数量与最终画面。

通过原生节点回读核对文本、位置、宽高、字号、字重、颜色、连线和层级。转换可能归一化空背景形状的无文字默认属性；将可见内容与无可见影响的差别分开，不掩盖实际文本变化。

原生 raw 更新可能新增节点，不是原位修改。已有板先导出、对比本地和用户手改；不要把整份 raw 再次追加上去。用工具支持的定点方式修复，或合并手改后写入新空板、验收后替换授权旧块。

## 文字溢出的根因与处理顺序

SVG 看起来正常但飞书越框，常见原因是目标字体和字重的实际宽度不同，原生文本框额外折行，而背景仍是固定高度。节点几何检查只能发现框的问题，不能证明字形没有越界。

1. 用目标字号、字重、字体测量文字，先确定自然语义换行，再决定容器尺寸。中文、数字、百分号、斜线、箭头和中英混排要一起测。
2. 给文本框留可校准的宽高余量；不要把固定倍数当永久保证。数字与单位尽量在一起，长句按语义分行。
3. 容器随文本行数增长，相邻模块随之让位。优先缩短重复表达、增加宽度或拆分内部层次，不靠不断缩小字体硬塞。
4. 检查文字实际边界、行数、行距、到容器边缘的距离；检查画布外框、列边界、底部注释、窄数字卡和相邻关系。
5. 修一处后看所有同类框及相邻节点。加宽可能侵占邻列，加高可能压住下一块。
6. 将 UI 修复同步到可重放的源文件／几何补丁，重新生成不会复发；保留源、payload、远端回读与版本对应关系。

## 四层验收

| 层 | 能证明什么 | 不能替代什么 |
|---|---|---|
| 本地 SVG/PNG 与测量 | 本地字形、内容和容器布局 | 飞书字体与换行 |
| 原生回读 | 节点内容、几何、样式、连接完整 | 实际字形没有越界 |
| 飞书服务预览 | 转换结果的大致布局、内容出现 | 高倍率下所有细节 |
| 实际浏览器 | 目标页面真实显示、编辑、重开 | 来源真实性与用户主观喜好 |

浏览器先整体看结构，再在可阅读比例逐区检查全部文字。重点检查窄框、长句、数字单位、末行和页底；选择一个文本节点进入编辑状态但不改字，退出并重新打开。操作后回读，确认没有误拖节点或改内容。保存覆盖区域与截图索引。

窄窗口无法使用完整画板时，可临时扩大验收视区，并在完成后恢复。不要用缩略图、一次预览或“导出成功”冒充全部检查。若无法实机检查，明确记为未验证，保留已完成的本地产物与原生回读。
