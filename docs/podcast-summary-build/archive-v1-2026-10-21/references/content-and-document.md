# 内容理解与文档规则

## 一份理解，三种表达

先回答五问：本期真正追问什么；讨论靠什么推进；哪些信息会改变理解；哪些模块共同回答中心问题；每块用什么形式最容易理解。将答案写入工作区内容方案，不把思考日志写进学习页。

| 类型 | 主线 | 常见失真 |
|---|---|---|
| 叙事／人物 | 处境与目标 → 事件与选择 → 结果 → 认识变化 | 只列年份、补造动机或圆满结局 |
| 讨论／政策 | 变化 → 影响对象 → 各方解释 → 取舍与条件 | 消除分歧、把建议写成事实、凑固定五栏 |
| 机制／技术 | 问题 → 组成 → 运行 → 结果 → 边界 | 堆术语、箭头不解释关系、没有失效条件 |
| 研究／案例 | 主张 → 方法与证据 → 结果 → 其他解释 → 支持范围 | 相关当因果、个例当普遍、预测当事实 |
| 方法／经验 | 目标 → 前提 → 步骤与分支 → 检查 → 失败 | 省条件，替节目补出没有的方法 |
| 多主题访谈 | 反复出现的问题，必要时保留多条相对独立的线 | 强编一条统一主线、每问一答都升为标题 |

一集可混合类型。模块多少由实质内容决定；某一维度没有材料就不填。数字紧邻所支持的判断，不另建脱离语境的数据仓库。

## 总结：读者能复述整期

写成连贯短文，交代中心问题、为何讨论、主要解释或冲突、关键转折和结论或未决问题。让各段承担不同推进作用；篇幅随复杂度，不限定四段。隐藏图和要点后，总结仍能独立理解。

观点用明确主语，必要时点名讲述者。叙事保留因何改变；讨论保留各方前提；解释说清机制；研究区分证据强弱。没有达成一致就保留分歧，不为收尾造一个“共同结论”。

只挑支撑主线的数字与例子。少写没有展开的“深刻影响”“复杂博弈”等抽象词。任何一段删掉都不损失推进时，合并或精简。不要复制要点标题或把总结写成整页目录。

## 关键要点：读者能具体使用

短内容用编号列表；多个判断共同回答一个问题时组成模块。标题交付信息，例如“缴存金额与可贷额度是两种约束”，比“政策信息”更有用，但不为追求判断句歪曲原意。

每块先给核心判断，再按材料补“依据／机制／例子／条件／争议／可用启示”。不要求每块凑齐六项；没有的数据和建议不补造。用完整自然句解释，不写省略到读不懂的短语。

各块应能独立理解。重要数字带必要的单位、年份、对象、分母、适用范围；例子与普遍规律分开，观点与事实分开。多个地方引用同一数字，核对口径一致。

多个约束共同影响一个结果、选项跨多个维度、因果有中间条件、方法存在判断分支时，考虑插入局部图。图放在相关模块旁，展开难点；一句话即可说明的关系保留文字。

## 总览：读者能建立全貌

总览是实质知识的覆盖，不是逐句转写：重要主题、机制、数字、分歧、条件都有落点，广告和重复不占位置。缩小看到结构，放大看到判断依据；只有标签和没有说明的数字不算覆盖。

三部分可重复核心判断，但各有用途：图表达关系，总结解释推进，要点展开依据。不要把同一组句子复制三遍。

## 数字、勘误与来源

- 依次核对原文、发布方勘误与数据图；转写可能认错数字、术语、专有名词。
- 如原文有口头纠正，独立正文采用纠正后的数值，原始档案仍保留前后原话。
- 不同年份／地区／群体的数据先解释差异，再决定能否比较。只有同一整体的互斥部分才画精确组成比例。
- 事实、讲话者观点、节目建议、编辑推论分清归属。推论需有依据，内容总结不自动升级为个性化建议。
- 未核验的节目时期政策写成“节目介绍／录制时／某城市示例”，不写“目前统一适用”。用户要求现行核验时另查权威来源并标注日期，将结果与节目原话分开。
- 无法解开的矛盾就近标明具体疑点；不要悄悄修成一个貌似正确的数字。
- 原文位置、证据对应表保存在工作区；正文只保留帮助读者理解的具体来源，不堆时码导航。

## 新文档的默认组织

按 `assets/note-template.md`：播客信息（基本信息、Shownotes）→ 关键内容（总览、总结、关键要点）→ 思维导图与文件 → 个人思考 → 延伸资料 → 原始资料附件。

这是新页默认值。更新时先读用户当前标题、层级、栏目顺序和位置，别恢复旧模板。只改用户要求的部分；局部详图放到其所属要点，用户另有位置要求则遵循。

## Shownotes 与图片

维护发布方介绍、参与者、补充资料、勘误与内容图片，保留必要链接、图注和出处。原图按原段落顺序嵌入，图例、坐标与字都要可见；不能只写一个“查看原图”替代上传。

保存图片 URL 与本地文件映射，核对不是封面误配或相邻文章图片。已存在且未变化的图直接保留；新增或替换时查重。图片获取失败就报告是哪张，不悄悄漏掉，也不画一张猜测图冒充原图。

无效链接不能伪造为可用。来源推广是否保留取决于用户已确认范围；独立总结、要点、总览去掉推广。正文不加“以下为发布方摘录”“完整内容已整理如下”等导语。

## 字体强调与间距

| 表达 | 用途 | 克制方式 |
|---|---|---|
| 加粗 | 核心判断、概念、模块入口 | 只读加粗应能串起主线；普通依据用正常字重 |
| 高亮 | 最需记住的主张、重要阈值或差异 | 同屏少数重点；不因每段都有数字就都标 |
| 下划线 | 容易忽略的条件、口径、适用限制 | 小段使用，避免整段像链接；正文格式不支持时保留语义 |
| 标题 | 信息分组和阅读顺序 | 不把单句段落都升成标题，不跳级 |

飞书各级标题前若是正文、列表、图片、画板或附件，插入一个空段落。文档开头及连续标题之间不另加；重跑时先检查已有空段。Markdown 用空行表达；不要为了实现空行而往文档塞占位字符。

删除制作过程、版本号、节点数、工具说明、泛泛来源导语。必要的数字日期、范围限定、出处和文件用途可以保留。不要删掉看似冗余却改变结论的条件。

## 个人记录

保留“我的思考／与我的关系／下一步行动”或用户的现有命名。用户已经写过的内容原样保留，润色需有授权。没有提供时留空或“待填写”；不把“我意识到”“我计划投资”等写成用户的感受或行动。节目中的行动建议放知识模块，不能混入个人记录。

## 两个写作示例（合成材料，只学组织）

**输入 A**：访谈讲述者先在大公司学流程，后来创业，产品首年失败后回归团队；她认为应先积累协作经验，另一位嘉宾提醒个体机会窗口不同。

**输出方向**：总结沿“为何离开 → 首次失败暴露了什么 → 如何改变选择 → 另一种前提”推进。要点展开流程能力与产品判断的差异。总览用带选择分支的时间线；不能补出收入、年份或“大家都同意先打工”的结论。

**输入 B**：两个城市分别按余额 15 倍、18 倍核贷；嘉宾举一地月供不超过收入 40%；甲觉得取钱付租有用，乙取出后被消费而选择留存。

**输出方向**：保留城市条件，不能合成“全国取 min(18 倍余额, 40%收入)”公式。总结说明同一制度在不同现金流习惯下产生不同选择。要点展开各自前提；总览用地方约束与资金路径对照，只有来源明确支持的同城约束才汇合。
