# 合成播客全文：三次转身以后，怎样判断一份工作适不适合自己

本文件是离线评测用完整合成材料，人物与节目均为虚构，不是现实职业建议。

00:00 主持人许禾：今天请林舟谈三次换工作的经历。我们关心的不是从大城市回到小城市是不是更幸福，而是人在什么条件下改变判断。

02:10 林舟：第一份工作在甲城的广告公司。我做了三年，最后一年带六个人。我原来觉得带团队代表进步，但自己每周花在客户协调上的时间越来越多，真正写东西的时间变少。没有统计具体工时，不要把我的感受写成行业调查。

06:20 林舟：第二份是在乙城一个文化空间。我搬过去前只试住了四天，看见了安静，却没有看见运营的重复劳动。我以为换城市能解决疲惫，后来才知道我讨厌的是没有自主权，地点只是其中一个条件。

10:00 许禾：所以你后悔离开广告公司？

10:30 林舟：也不是。文化空间这两年让我学会预算和排班，得到的是另外一类能力。但晚上和周末要在场，我没能像想象的那样多陪父亲。城市离家近，时间却未必可用。

14:00 林舟：第三次我没有立刻辞职。我把每周一个下午留给独立项目，试了八周。三位老客户答应续约，才开始谈减工时。客户口头答应不等于稳定收入，这一步只减少不确定性，不能消灭它。

18:20 许禾：你现在自由职业，那是不是应该劝大家都先接副业？

18:50 林舟：不能这么说。我能尝试，是因为伴侣收入稳定，而且双方谈过家庭开支。我预留了九个月必要开支，不是九个月原工资。我没有给出金额，也没有说九个月适合所有人。照护负担、合同限制和身体状况，都可能让同样的方法不可行。

23:00 许禾：我自己的经历相反。上份工作的加班让我失眠，已经无法用下班后的时间做实验。我先离开，住回父母家调整了两个月，才找下一步。我不同意所有人都必须“验证完成再行动”。

26:40 林舟：这个分歧成立。如果继续留下会损害身体，先退出可能合理。我说的八周实验，是在还撑得住、也有一点可支配时间的情况下。我们不是在评谁更勇敢，是在看哪种风险目前能承受。

30:10 许禾：那要留下什么判断方法？

30:40 林舟：先把不满拆成任务、关系、节奏、地点四类，看看哪类真的在起作用。能在原岗位做小范围调整的，不一定马上换公司。要试新路径，就让试验回答一个具体问题，比如有没有愿意付费的客户，而不是只证明自己很喜欢。

34:30 许禾：我补一条，把已经无法承受的身体信号单独列出来，它不能被漂亮的验证表格抵消。我们最后没有找到一套人人通用的换工作步骤。

38:00 林舟：我的三次选择都得到一些东西，也放弃一些东西。现在最重要的是能决定下午做什么、父亲需要时能腾出时间。以后家庭条件变了，我也可能重新做全职。

41:00 许禾：结束前提醒，本期是两个人的经历，不是代表性样本，也不保证换城市或自由职业会改善生活。
