单次中位耗时 14.33 秒。CLI 报告的总 input+output tokens 为 2,735,344，包含多次工具往返累计输入；不能当作净新增文本量或账单金额。详见 [触发汇总](trigger-summary.json)。

## 有／无 Skill 内容对照

两份完整合成来源，每个条件生成一次，共 4 份 Markdown/SVG。配对运行使用相同设置和同一输入，不访问真实账号。三位独立上下文评审不知道 A/B 对应条件，均实际查看四张 PNG；主观分取逐项中位数，R6/R7 由脚本评分。

| 样本 | 有 Skill | 无 Skill | 主要观察 |
|---|---:|---:|---|
| 人物访谈 | 65/65 | 61/65 | 有 Skill 总结更完整地解释认识变化，并内嵌 Shownotes 原图；无 Skill 原图仅是链接，摘要较简略 |
| 补助讨论 | 64/65 | 64/65 | 两组均能分清城市、时期、资格、调查口径及未决观点，且保留原笔记非目标内容；实用质量判平手 |
| 均值 | 64.5/65 | 62.5/65 | 归一化约 99.2 与 96.2；样本少且多数项触顶，不据此声称显著或普遍增益 |

主要弱项：有 Skill 的讨论摘要没有交代节目结尾的租客查询顺序，对后续评价方向也略有省略，但要点和总图已经展开。无 Skill 个别措辞把“调整后”增强为“恢复后”，把“申请年度”缩成“本年度”。这些局部偏差无需写成针对具体例子的 Skill 禁令，通用的完整总结、忠实与口径规则已经覆盖。

R2、R4、R5、R7、R8 两组均触顶；R3、R6 的均值差也在脚本的 NO-SIGNAL 阈值内。这些项不用于论证增益，下一轮应换成更难的差异化考点。保留其回归约束，不因两例都通过就删除用户明确的保护规则。

三位评委的分数范围通常为 0–1 分。这里只重复了评审，**没有重复生成**，不能把评委一致当作生成稳定性。评委仅获得去身份化的简化执行证据，部分具体哈希和估算细节不能独立复核；真实工具轨迹仍保存在本地 runs 中。详见 [评分汇总](content-score-summary.json)、[考点审计](rubric-audit.json)、[人工抽检](06-人工抽检.md)。
