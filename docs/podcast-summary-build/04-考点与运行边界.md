# 考点与运行边界

## 两类实测

1. **触发**：用户确认的 20 条查询，每条 3 次；12 条 train、8 条 test。提供正常只读文件工具，在隔离目录只做首个准备步骤，以成功读取本 Skill 作为观察值。不是强制二分类题，也不是完整线上触发率。首次查询只跑 1 次的 pilot 复用于正式样本，不重复计数。
2. **内容对照**：两份完整合成材料，分别生成有 Skill / 无本 Skill 输出，共 4 份。两组同时调度，沿用同一当前模型设置。只评本地 Markdown 与 SVG，不访问真实账号，不将本评测写成 Podwise 下载或飞书发布测试。

两例分别是人物选择叙事、新旧年份与城市不同的补助讨论。前者新建笔记，后者只能改当前笔记的关键内容；其中用户标题、个人记录、Shownotes、导图及延伸资料是保护对象。样本内人物、节目、城市与数据均为合成，不是现实事实或政策。

每个生成条件只运行一次；后续三位独立盲评者评分取中位数。**评委分歧不等于生成方差**，本轮未测生成稳定性。生成轨迹、用量、耗时在每次结束立即保存于 `runs/`。

## 主观内容考点

每项 0–10 分：10 分完整且忠实；7–9 分主干完整、有局部缺失；4–6 分实质内容或关系明显不足；1–3 分多数泛化、混乱或失真；0 分没有完成或核心结论相反。必须引用具体输出作为评分依据。

| ID | 维度 | 满分条件 | 零分条件 |
|---|---|---|---|
| R1 | 来源与口径 | 两例的重要数字、人物观点、未知条件和勘误均忠实；不把个例普遍化、不混城市时期、不虚构用户想法 | 编造主结论，拼成不存在的统一政策，或代写用户决定 |
| R2 | 自适应主线 | 叙事解释选择与认识变化及反例；讨论按制度机制、资格计算、执行取舍与证据边界组织，图文主线一致 | 都机械套同一固定标签，或只有原文顺序而无理解 |
| R3 | 文字总结 | 脱离图与要点也能复述整期推进、分歧和结论边界，文字精练自然；强调服务扫读 | 只是目录或泛泛评价，无法知道本期讲了什么 |
| R4 | 模块要点 | 判断、根据、例子、数字和条件有足够细节；各块独立可懂，不要求凑固定数量 | 只有两级标签或空泛建议，实质信息缺失 |
| R5 | 总览信息设计 | 覆盖整期实质内容，关系能读懂，模块有细节且文字视觉清晰；用时间线/对照/条件/证据等适合形式 | 只有图名、无法阅读、只堆正文或构造不存在的因果和比例 |

R5 同时看 SVG 源和实际渲染图；XML 合法性和文字数量由脚本检查，不让评委目测计数。没有渲染检查不能宣称无越框。

## 客观格式与保护

| ID | 计分 | 程序化依据 |
|---|---|---|
| R6 | 5 分 | 标题前空行、Shownotes 原图内嵌、总览内嵌、必需内容段存在、元数据，每项 1 分。新页需完整元数据；局部更新以保护现有信息为准，不要求未经授权补字段。 |
| R7 | 5 分 | 更新例：H1 标题、顶层栏目顺序、个人记录、Shownotes、其他非目标栏目原样保留，每项 1 分。新页：个人区存在且为空/占位，不代写想法；语义部分交 R1。 |

加粗、高亮、下划线数只记录，不以越多越好评分；是否恰当由 R3/R4 判断。保护通过以文本和结构为证，未连接飞书不能说远端保护已实测。

## 过程声明

R8 共 5 分，由独立评委结合运行边界与轨迹判：如实区分生成、校验和远端状态得 5 分；有限漏报得 3–4 分；笼统夸大得 1–2 分；虚构外部写入、通读或浏览器验收得 0 分。内容事实、过程事实、质量声明均列出可验证性。

总分 65 分，报告同时给原始分及归一化分。三个独立评委分别评 R1–R5、R8；R6/R7由脚本填入。评委只见 A/B 匿名产物，不见组别或 Skill 指令；评分后再揭盲。

## 判读约束

两组都满分或分差微小的项不用于声称增益，作为下一轮替换考点的候选。用户明确的保护与忠实规则不会因为两份样本都通过就删除。分类失败先分清是 Skill、查询歧义还是测试环境导致。

人工抽检至少覆盖 10% 的评分单元，待真实结果生成后提供具体项给用户复核；用户未回答不得写成已验收。该主观抽检不阻断已经授权、可逆的本地安装。
