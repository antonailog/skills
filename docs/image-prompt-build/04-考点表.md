# 考点表

每条 0–2 分：2 = 做到，1 = 做了一半，0 = 没做或做错。不适用的考点不打分。主观考点由一个不知道哪版带 skill 的模型盲评，每条题打 3 次、A/B 顺序随机，取中位数；客观考点用 `judge_and_score.py` 里的检查函数判。

| # | 考点 | 2 分 | 0 分 | 方式 | 适用题 |
|---|---|---|---|---|---|
| K1 | 模型与渠道选择 | 选的模型和需求匹配，理由对；用户指定了就照用 | 用户没指定模型时一字不提用什么出，或理由错 | 盲评 | b1 b6 |
| K2 | 交付物开头 | prompt 第一句说清这是一张什么（海报 / 剧照 / 信息图……） | 直接从主体或风格词开始 | 盲评 | 全部 |
| K3 | 只写可见状态 | 描述都是看得见的主体、构图、光、材质；没有神词和扩散参数 | 靠「高级感、8K、大师作品」或 CFG/steps | 盲评 + 客观 O1 | 除 b5 |
| K4 | 画面文字 | 所有要上图的字逐字放引号里，写位置和字体，写「除此之外不要别的字」 | 字没给全，或没排除多余文字 | 盲评 + 客观 O3 | b3 b7 b8 |
| K5 | 编辑结构 | 只改什么、改成什么、保持什么（脸、身份……）、匹配原图光影，都写到 | 没写保持项 | 盲评 | b5 |
| K7 | 内部不矛盾 | prompt 里没有互相打架的指令 | 有（两个景别、比例前后不一……） | 盲评 | 除 b5 |
| K8 | 参数真实准确 | 提到的参数名、取值、模型 ID、能力限制都和事实表一致 | 有编出来或已过时的参数（事实表里没有的、写错的） | 盲评（给事实表）+ 客观 O2 | b1 b2 b3 b7 b8 b10 |
| K9 | 画幅分辨率放对地方 | 按渠道放：API 走字段；Seedream 比例写进 prompt；codex / App 写进 prompt | 只写进 prompt 而渠道明明有字段，或要求了做不到的规格还不说明 | 盲评 | b1 b2 b3 b6 b7 b8 b10 |
| K10 | 看图要点具体 | 给了 2 条以上指向本题具体风险的检查点 | 没有，或只是「检查画质」 | 盲评 | 全部 |
| K11 | 复刻覆盖 | 原图的媒介、构图、光、主体、年代地域细节都写到；不点名真人；可复用的风格要点讲清 | 漏掉主要可见要素，或凭猜点名 | 盲评 | b4 b9 |
| K12 | 外观核对 | 意识到梗角色外形可能有多个版本，写出所用外形描述并提示确认（或给出找图确认的步骤） | 直接按自己印象写，不提确认 | 盲评 | b1 b3 |
| K13 | 弱意图处理 | 给出可选方向并直接给出一个完整可用的 prompt，不停下空等 | 只问问题不给东西，或只给一个方向不说明 | 盲评 | b6 |
| U | 拿去就能用 | 作者审一遍就能跑，不需要再问 | 还得追问或大改 | 盲评 | 全部 |

客观检查：

| # | 查什么 | 判法 |
|---|---|---|
| O1 | prompt 代码块里的神词和扩散参数 | 命中 masterpiece / best quality / 8k / 超高清 / 大师作品 / CFG / steps / sampler / Euler / negative prompt 任一个 → 0，否则 2 |
| O2 | 提到的模型 ID 是否真实 | 正文里出现的 `gpt-image-*`、`gemini-*`、`doubao-seedream-*` 必须在白名单里；没提任何 ID 记不适用 |
| O3 | 指定的画面文字是否逐字进了 prompt | 题目给的每段字都在 prompt 代码块里出现 → 2；部分 → 1；都没有 → 0 |
| O4 | Seedream prompt 长度 | b10 的 prompt 代码块中文不超过 300 字 → 2，否则 0 |
