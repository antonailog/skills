# 调研报告事实核对（2026-11-06）

主料（作者工作区的 `知识/调研/如何写好文生图prompt/deep-research-report.md`，不在本仓库） 是 ChatGPT 深度调研的导出，文中 `citeturn…` 引用标记已经失效，点不回原文。参数类说法全部重新核过：两个子 agent 分头抓官方文档原文（OpenAI 一组，Google 和火山一组），我再从下载下来的原文里抽查了关键几条（complexity 默认 high、GIF 帧数范围、2.6 不支持 Responses、Nano Banana 2.1 模型 ID 和 14 张参考图的分配、Seedream 5.0 Pro 的尺寸档位和 300 字上限），都对得上。来源链接见 `skills/image-prompt/references/models.md` 文末。

## 报告说错或说漏的

| 报告的说法 | 实际 | 影响 |
|---|---|---|
| markup 是 2.6 新增 | 2.5 和 2.6 都支持 | 参数卡写成两者都有 |
| 2.5 的尺寸限制（3840、16 倍数、3:1、3.69MP 实验性） | 对，但漏了总像素 655,360–8,294,400；而且这套限制不能套到 2.6 上，2.6 只写了「16 倍数、1:3 到 3:1」 | 2.6 不承诺 4K |
| 没提 | 2.6 只能走 Image API，Responses 和 Batch 都不支持 | codex 内置生图因此不会是 2.6 |
| GIF 用 sprite sheet 做 | 2.6 返回原生 GIF，帧数和每帧时长是参数；sprite sheet 只是别的模型的退路 | 模板 13 分两种写法 |
| Nano Banana Pro 是 `gemini-3-pro-image` | 对；preview 版 2026-06-25 已关停 | 参数卡注明别写 -preview |
| Pro 支持 1:4、4:1、1:8、8:1 | Gemini API 文档说只有 2.1 / NB2 有，Vertex 的 Pro 页又列了，两处矛盾 | Pro 不用极端比例 |
| 14 张参考图（未分配） | Pro：物体 6、人物 5、风格 3；2.1：物体 10、人物 4、无风格名额 | 选模型时用得上 |
| ImageConfig 只有 aspectRatio 和 imageSize | 对，但这是旧接口；现在默认 Interactions API，字段是 `response_format.aspect_ratio / image_size` | 参数卡两种都写 |
| Imagen 的 GenerateImagesConfig 有 guidance、seed | Imagen 已整体关停 | 参数卡写「和这里无关」 |
| 报告没写 Nano Banana 2.1 和 Seedream | 2.1：`gemini-nano-banana-2.1`，10-06 GA，Pro 的高效版；Seedream 5.0 Pro：最高 2K、prompt 中文 ≤300 字、不支持组图、默认加「AI 生成」水印、Lite 11-24 关停 | 两家各写一节 |

## 报告说对、直接用的

- 「视觉规格书」的写法：交付物开头、只写可见内容、文字加引号写位置和次数、编辑分「改什么 / 保持什么」、一次改一处——OpenAI 和 Google 官方指南原文都有对应句子。
- 不写 sampler / steps / CFG / seed：三家的参数表里都没有。
- 语义负面提示（「空无一人的街道」代替「不要车」）：Google 文档原文。

## 还没确认的

- ChatGPT 里能不能选 Flare / Sunburst、调 quality；模型选择器里的「推理强度」是不是 complexity。官方公告页和帮助页抓取返回 403。
- 2.6 的尺寸上限。
- Nano Banana 2.1 传 seed 报错只在 Vertex 文档写了，Gemini API 没写。
- Seedream 传 seed / guidance_scale 是报错还是被忽略；火山提示词指南能否照搬到 5.0 Pro。
- codex 内置生图的具体型号（二进制里只出现 gpt-image-2 及更早的名字）。
