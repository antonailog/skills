# html-deck：需求与已定的事

建包过程记录（skill-build S0、S1）。skill 本体在 `skills/html-deck/`。

## S0 为什么单独做成 skill

做 HTML 演示稿这件事会反复用（演讲、课程、汇报、产品演示），有固定的脚本（编辑服务、离线打包、网站版生成、检查），还要跨会话保持同一套做法。仓库里没有做演示稿的 skill；相邻的各管各的：pptx 出 PowerPoint 文件，archify 出图解和单页说明，knowledge-canvas 出知识画布，forge-design-lab 定网站设计参数。按完整档做。

## S1 来源

做法来自作者 2026-11 一场线下分享的讲稿：19 页 HTML 讲稿、编辑模式、离线播放包、博客网站版，五轮批注改稿。

### 第一版功能（13 项新增，加已有功能）

已有、全部带上：16:9 画布缩放、翻页和网址定位、按需分步、页签、嵌入网页（大窗口渲染再缩小）、断网换截图、视频、备注（N）、全屏（F）、打印；编辑模式（改字、删除、撤销、字号粗细颜色、拖动、批注带截图、只写回舞台段、版本检查和备份）；离线播放包；网站版生成。

新增第一版：翻页笔兼容、演讲者视图、总览跳页、翻页动效、分步动效、数据动效、尊重「减少动态效果」、数据图表组件、大数字和对比卡、字体打包、自动检查、源文件隐私扫描、二维码生成。

以后：网站版转长文阅读、网页嵌入加标注、录屏视频章节。

不要：时长预算与彩排计时、激光笔和临时画笔、章节目录和进度、练习和小测验页、导出 PDF、导出 PPTX。

### 写成默认做法的用户纠正

- 要讨论的事先讨论，不自由发挥；设计选择给可点选的讨论页，排版问题用真实内容渲染出来挑（线框图被否过）
- 分步只用在需要渐进讲的页，一张图不切分
- 标题在粗线上方，不放分区名；数据用引用样式带出处，看不懂的表格改成陈述句或大数字
- 少用实心色块，红色只留给重点
- 样例页讲「怎么做」和「输入输出」，不直接嵌原始页面
- 公开版不放备注和真名；嵌入的页面和数据，发布前扫解压后的源文件，不能只看页面
- 先不砍内容，最后按时长删减
