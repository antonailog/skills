## 测试（都在 scratchpad 的临时项目上跑）

- 组件样张 × 4 套风格逐页渲染，修了：图表字太小（改成翻到那页按实际尺寸画）、大数字和对比卡被拉满整页、编辑书卷大字没用衬线、刻度零碎数（改成取整）、演讲者视图「最后一页」提示类名和 .end 撞了
- 引擎交互：PageDown 23 下走完 15 页；黑屏按键恢复不翻页；总览 15 格点选跳页；数字滚动停在原值；演讲者视图两个窗口互相同步（含镜像的当前页、下一页）
- 编辑模式（serve.py）：双击改字、[ ] 调字号、拖动、批注、⌘S 保存都写回；文件里没混进图表 svg、分步标记、页码、data-gen；备份生成；保存前后对比只多三处改动
- check.py：抓到缺文件、在线页没截图、故意塞的溢出（整页超高 60px 和具体超出的块）
- render_styles.py + discussion.py：4 套 × 3 页截图，讨论页点选、备注、复制「已复制」
- fontpack：样稿用到的字 474 KB，7 秒（有缓存后更快）
- privacy_scan：干净目录不报；路径、邮箱、手机号、密钥、IP 都抓到；v1.2.3.4 不误报
- package.py：24 个文件 0.6 MB；解压后 check 联网断网都过，断网时字体用包里的子集
- website.py：备注删光、data-web-shot 换图、data-web="remove" 整块删（含嵌套）、--replace、data-public、data-top
- validate_skill.py：0 错误 0 警告，正文 127 行，红线 4 条

## 独立审查（2026-11-23）

两个只读 agent 分头审：一个对照文档和代码，一个专挑代码错误并逐条复现，共 26 处代码问题加十几处文档不符。修完后用审查留下的复现脚本和新写的用例重跑：

| 问题 | 怎么修的 |
|---|---|
| 大数字滚动把 `42<small>%</small>` 抹成纯文字，编辑模式保存时写进文件 | 只动装数字的那段文字 |
| 网站版删备注只认 `<aside class="note">` 一种写法，别的写法会公开出去；HTML 注释不删 | deliver.py 改用标准库 html.parser 建树，class 里带 note 的都删、注释都删，删完还有就不出 |
| 离线包漏文件：单引号、srcset、style 里的 url()、嵌入页自己的样式和图片；`../` 拷到包外 | 引用都从解析树里收；嵌入的本机网页整个文件夹带上；指到讲稿目录外的直接停 |
| 编辑服务不校验来源，任何网页都能往批注.json 写字 | 每次启动发一个口令注入页面，写请求必须带；只认本机 Host；保存加锁 |
| 拖动图表、二维码存不住；演讲者窗口里也注入了编辑器；断网时保存把 `.box.off` 写进文件；打字不自动存 | 选中外框；预览窗口不开编辑；保存时去掉；打字后自动存，关页前有未存内容提醒 |
| 演讲者窗口按 B 只黑自己；点预览后键盘失灵；主窗口刷新后不同步 | 黑屏状态互相同步；预览不接收点击；演讲者窗口每秒报到一次 |
| 其他：`#99` 越界白屏、总览是一次性快照、坏选择器让引擎整个不跑、标题 `..` 当包名、图表标签比数值少时画出界、开发和打包字重不一致、Windows 路径、网站版 `-o` 会清掉已有目录 | 逐条修 |
| 隐私扫描只扫几种后缀；`logo@2x.png`、`Chrome/129.0.0.0` 误报；`+86`、带空格的手机号漏报 | 不分后缀扫全部非二进制文件和文件名，二进制的列出来请人看；补了这几种写法 |

修完再派复审，又查出 8 处，其中两处是上一轮修出来的：翻页中途切走时数字复原仍会抹掉小字（复原的另一条路径没改到）；嵌入页「整个文件夹带上」会把 `嵌入/` 里换成截图的私人页面和草稿带进网站版。改成：从 index.html 起顺着嵌入网页、样式表的引用一层层收文件，只带用到的。其余：注释按解析器给的真实起止删（`<!x>`、`<!-->` 这类写法）、没关上的 `<p>` 遇块级元素自动结束、演讲者窗口黑屏时自己不黑只在顶栏提示、编辑服务校验请求结构、只接收演讲者视图这组窗口发来的消息、两处说明。

第三次复审剩 1 处：嵌入页里指向文件夹的链接（`<a href="./">`）会把整个文件夹带走。改成文件夹一律不带、嵌入页里的 `<a>` 跳转链接不算要带的文件；另修了主窗口刷新后演讲者窗口的黑屏提示没清、`<p>` 里隔着 span 的块级元素被当成备注一起删。用复审留下的复现脚本重跑通过。

已知没修：分步标在第二个页签里会在第一个页签显示时就走掉，写进了 components.md（分步只标在页签外）。

公开仓库隐私：建包时的两个讨论页（风格页里有那场分享的截图）挪到私有笔记仓库；文档里的讲稿名和本机路径改成泛称。
