# 《research-with-gpt Skill 设计文档》

> 阶段：S2 设计 · 状态：待评审 · 档位：轻档（SKILL.md + 一份范例）· 2026-11-09

## 0. 为什么单独做

满足：☑ 会重复使用 ☑ 容易被路由错 ☐ 有脚本能省力 ☑ 要跨会话接上

- 不扩展 deep-survey：它是 AI 自己查、三个角色写报告。这里是 AI 出 prompt、你去 ChatGPT 跑、隔几天把报告拿回来。流程和产出都不同，塞进去会让 deep-survey 变胖、两条线互相干扰
- 不只靠记忆：记忆只提示做法，管不住目录和格式，报告回来时下个会话不知道去哪找
- 不做：每次都要重新交代背景、格式、放哪

## 2. 设计

### 2.1 要解决的问题

替你把「想搞懂一个主题」变成几条能直接扔给 ChatGPT Deep Research 的 prompt，报告回来后接着整理。

### 2.2 定位与边界

**定位**：Deep Research 的出题人和收卷人。像一个懂行的研究助理：先帮你把真正想搞懂的问题问清楚，再拆成几份互不重叠的研究任务书；报告回来后先告诉你每份说了什么、哪里互相矛盾、哪些没答上，再等你定怎么用。

**核心立场**：Deep Research 跑一次几十分钟、次数有限，方向错了整轮白跑。所以出题前那一两轮对话最值钱；prompt 宁可多拆几条，也要每条问题具体、互不重叠。

**范围**：一次一个主题，拆 5–8 条。

| 不处理 | 交给 |
|---|---|
| 没点名 Deep Research / GPT，只说「深度调研 X」 | deep-survey（AI 自己查） |
| 给模型写任务指令（打分、提取、分类） | prompt-craft |
| 收藏别人写好的 prompt | prompt-vault |
| 不在调研文件夹里的单篇报告转导图 | book-to-mindmap |
| 用 Codex 联网查 | 不做 |

**很像但不该触发**：
1. 「深度调研一下国内 AI 陪伴产品赛道，出份报告」→ deep-survey
2. 「帮我写个 prompt，让 GPT 给小红书评论按情绪打分」→ prompt-craft
3. 「这条 deep research 的 prompt 写得不错，存进 prompt 库」→ prompt-vault
4. 「这份 PDF 报告转成思维导图」（不是调研文件夹里的）→ book-to-mindmap

### 2.3 触发与路由

应触发：「用 deep research 调研 X，给我 prompt」「这块不懂，拆几个 GPT deep research 方向」「deep research 报告下好了」「AI 设计那几份报告回来了，整理一下」

抢活的隔壁：deep-survey（最大）、anthropic-skills:deep-research、prompt-craft。deep-survey 的描述里加一句排除，改前先快照。

| 信号 | 走哪段 |
|---|---|
| 新主题，`知识/调研/` 下没有对应文件夹 | 出题 |
| 说报告回来了，或 `2-报告原件/` 有新文件 | 收卷 |
| 「再补两条」「③ 没答好重出」 | 在原文件夹追加 prompt |

### 2.4 输出

**出题段**
1. 查背景：记忆、`知识/调研/`、`知识/学习/`、相关项目里已有的
2. 钢人轮：重述真问题 → 支持和反对你当前想法的最强论证 → 真分歧和关键变量 → 只问一个问题，停下等回答。还有关键没清楚的再来一轮，一轮只问一个
3. 交付：一行判断 → 方向表（编号、方向、为什么单列）→ 先发哪几条 → 每条一个代码块
4. 每条 prompt 六段，顺序不变：【背景】【这次调研】请回答（编号问题）、这次不用讲【交付结构】【写法要求】

**收卷段**
1. docx、pdf 转成 md 放 `3-报告转写/`，md 直接读
2. `4-摘要与对照.md`：每份一页摘要（对应哪条、核心结论、最有用的几条、没答上的问题）+ 一张对照表（共识、矛盾、只有一份提到的）
3. 消息里几行结论，问下一步：合成方法论 / 导图 / 发飞书 / 做成 skill / 补一轮 deep research

### 2.5 文件夹与失败处理

```
知识/调研/<主题>-<YYYY-MM-DD>/
├── 0-说明.md        真问题、方向表（每条发没发、回没回、对应文件）、下一步
├── 1-prompt.md      全部 prompt
├── 2-报告原件/      你把下载的 md / docx / pdf 拖进来，不用改名
├── 3-报告转写/      AI 转的 md
└── 4-摘要与对照.md   后续产出接着编 5-、6-
```

| 情况 | 怎么办 |
|---|---|
| 说放好了但文件夹是空的 | 给出文件夹路径，请你拖进来 |
| pdf 转不出字（扫描版） | 说是哪份，请你重新下 md 或 Word 版 |
| 报告对不上任何一条 prompt | 摘要里单列，问你归哪条 |
| 只回来一部分 | 先做回来的，表里标「还没回」 |
| 不知道是哪个主题 | 列出 `0-说明.md` 里还有没回的文件夹，问是哪个 |

### 2.6 辅助资源

- `references/范例-AI设计协作.md`：11-09 那 7 条 prompt 原文和方向拆法，出 prompt 时照着学格式

### 2.7 query 样本

1. 「我想系统学一下 agent 的记忆机制怎么设计，用 deep research 调研，你先给我 prompt」
2. 「MCP 和 skill 这块我一直没搞明白，帮我拆几个 deep research 方向」
3. 「想搞懂独立开发者怎么做海外 SEO，GPT deep research 跑一下，prompt 给我」
4. 「deep research 报告下好了，都放进 AI 设计那个文件夹了」
5. 「③ 那份回来了，其他还在跑，先看下这份」
6. 「上次那个 SEO 调研再补两个方向：外链和 AI 搜索优化」
